# 比較動画（Aさん vs Bさん）の型

元にした動画：海外で伸びている「同じ給料の2人、1人は家を買い、1人は借りる。10年後どうなる？」（約3分）。
**結果が出ている人の型をまねる**のが方針。テーマを入れかえて使う。見本：`src/examples/CompareExample.tsx`

## 伸びている一番の理由：「安心させる→崩す」が約30秒ごと
| 時間 | 安心させる | 崩す |
|---|---|---|
| 0:45 | 返済は家賃とほぼ同じ | 「でも足りないものがある」→隠れた費用 |
| 1:30 | 10年でこれだけ返した | 「でも注意！」→半分近くは利息 |
| 2:05 | 借りた人の勝ち | 「そう簡単じゃない！」→家の値段で逆転 |
| 2:30 | 家賃は捨て金じゃない | 「ただし、本当に投資するなら」 |
- 小さな「でも」が4回。そのたびに見る人の答えが変わる → 長くても最後まで見る

## 決まりごと
- **冒頭**：同じ条件の2人 → 違う選択 → 「10年後どうなる？」 → 「本当に計算してみよう」
- **前提**：数字を1つ言うたびに、画面に1つ足す（話だけの前提は離脱される）
- **「公平に比べるため」の一言**：相手側にも有利な仮定を置く → 反論コメントを先につぶす
- **答えは最後ではなく7割の地点で出す** → そこから崩す
- **分かれ目を1つの数字にする**（例：家の値段が年約0.8%上がるか）→「でも保証はない」
- **常識を崩す一言**（例：「家賃は捨て金」は単純すぎる）→ 人に話したくなる
- **±の対比でまとめ**、最後の一言は見る人への宿題 or 「自分ならこうする」

## 80秒前後に縮めるとき
- 前提は10秒以内／「でも」は2〜3回、間隔は約20秒／最後は「自分ならこうする」（体験は本当のことだけ）

## 流れの空欄テンプレ
1. 同じ条件の2人。Aは〇〇、Bは△△。10年後どうなる？本当に計算してみます。
2. 前提（数字1つ＝画面1つ）。
3. A側：まず安心させる →「でも」→ 隠れたコスト／見落とし。
4. B側：「公平に比べるため」の仮定。
5. 早送り → 10年後 →「でも注意！」払った額と本当に残った額の差。
6. いったんの結論（7割地点）。
7. 「ちょっと待って！」→ シナリオ3本 → 分かれ目の数字1つ →「保証はない」。
8. 常識を崩す一言。
9. ±まとめ → 宿題 or 「自分ならこうする」。

## 見せ方（映像の型）
- 冒頭：縦長のカードが2枚＋真ん中の丸。丸が「VS → ＝ → 10年 → 計算」と変わり、そのまま条件のカードに変身（ページは変えない）
- 役の色を全編で固定（A＝青、B＝ピンク、共通＝紫）。字幕の箱の色も役の色
- 章の扉（番号＋名前）→ 中身。片方ずつ見せる
- 中身を割る（ドーナツ）→ 差（カッコ＋差の数字）→ ハンコ
- 「ちょっと待って！」のハンコ → シナリオの横棒＋基準の点線 →「保証はない」
- ±の2列まとめ → 最後にチェックが入る
- 場面の切り替えは Board のページ送り（縮む→流れる→戻る）
