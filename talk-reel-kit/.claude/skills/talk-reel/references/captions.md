# 字幕のルール（src/talk/Captions.tsx）

- **語同期（カラオケ式）**：words.json の秒どおりに、言葉が1つずつ明るくなる。今しゃべっている言葉に色の箱
- 1枚の区切り：句読点・0.35秒以上の間・14文字。→ だいたい2行以内に収まる（`makeChunks` の数字で調整）
- 文字：極太ゴシック、白＋黒の太い縁（実写の上でも読める）、大きさ66px前後
- 強調（plan.ts の emph）：
  - 色：キーワード（名詞）＝オレンジ、良い結果＝緑、注意＝赤
  - `marker: true`：一番刺したい言葉に黄色のマーカー（1本に2〜3回まで）
- 位置：画面の下1/3（top≈1250）。下に薄い影を敷いて読みやすく
- まちがいは words.json の `w` を直す（秒は触らなくていい）
- 言い直し・「えー」は words.json から消すと字幕から消える（映像を切るのは別の作業）
