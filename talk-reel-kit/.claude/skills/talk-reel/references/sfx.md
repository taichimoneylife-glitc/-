# 効果音（public/sfx/）★この音だけを使う

ほかの音（合成音・ダウンロードした音）は足さない。音量の目安 0.2〜0.4（声より小さく）。
**0秒ちょうどには鳴らさない**（動画の頭の「ポン」は不自然）。

> 音域の目安：**低**=〜400Hz／**中**=400〜900Hz／**高**=900Hz〜。

## 一覧
> ⚠️ u01〜u10 の多くは**何回か鳴る音・長めの音**（u02＝2回「ポップポップ」、u07＝長い音 など）。
> **1回だけ鳴らしたい時は単発版（u02s / u03s / u05s / u10s）**を使う。同じ音を続けて鳴らす時は必ず単発版。

## 使い分け（迷ったらこれ）
- 図解・カードの出現：**u02s**（数が多い場面もこれ）
- 転換・ページ送り・全画面へ：**u03s**、大きな区切りは u07
- 寄る所・数字が増える所：**u05s**
- カウント：u06
- 数字のキメ・ハンコ：u04 か u08（1回だけ）
- まとめ・チェック：u10
- 締め：u07。u09 / u01 は「ここぞ」の1回
- 量：1場面に2〜4個。**高い音（u01/u04/u06/u08/u09/u10）は1場面に1回まで**（キンキンしないように、中音が主役）
