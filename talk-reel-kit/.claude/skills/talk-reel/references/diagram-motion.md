# 図解の動き（人気の図解リール「マーケ博士」2本の分析より）

デザイン（色・キャラ）はまねせず、**動きと見せ方の型**だけ使う。部品は `src/diagram/`。

## A. 1枚の大きな紙＋カメラ（cam.tsx の Camera）
- 場面の中では切り替えない。**カメラが寄る・引く・横に流れる**だけで次の説明に進む
- 動きは3〜8フレーム。最初ためて一気に動き、ピタッと止まる。動いている間だけ少しぶれる

## B. 1枚の大きな地図（board.tsx の Board）
- 全部のページを1枚の紙の上に格子状に並べ、点線でつなぐ
- ページ送り＝「縮む（約0.45倍・0.2秒）→ 点線に沿って流れる → 戻る」で約0.7秒
  - `kind: "kick"`＝新しい章（ためて大きく流れる）、`"fast"`＝同じ章の中（さっと）
- 山場で地図全体まで引いて、これまでの全ページを見せる（`{ id: "__map", trans, scale: 0.25 }`）
- 左下に進み具合（Stepper）。進むと丸が塗られて線がのびる

## C. 注目の所だけ明るく（Spot）
- 画面全体が3〜4フレームで暗くなり、注目の所だけ明るいまま＋黄色の太い枠
- 暗くするのは「ここを見て」の瞬間だけ

## D. 引き出し線つきの説明（Callout）
- 黄色い点 → 線が4フレームで伸びる → 白い箱（黒い太い枠＋ずらしただけの影）。キーワードだけ色

## E. 出方
- 「うっすら大きめ → くっきり」（ghostIn）：ポップより上品で速い
- 新しい箱は下から少し浮き上がる（rise）、札やハンコはポン（pop）
- 数字は必ずカウントアップ（0.3〜0.6秒）

## F. 文字
- 見出しは上（y≈190）に「小さい札＋大きな見出し」
- キーワードは**赤の明朝体**（SER）、本文は黒の極太ゴシック（K）
- 大きい数字は赤の明朝体＋小さい単位

## G. 図のパターン（よく使う）
| パターン | 動き | 部品 |
|---|---|---|
| アイコン→矢印→結果 | 矢印が伸びる→結果がポン | flow / Chip |
| 折れ線 | 軸が先→線が左から描かれる＋数字が増える | LineGrow |
| 比較の棒 | 棒が伸びる＋基準の点線 | HBars |
| 内訳 | ドーナツが色ごとに割れる | Donut |
| たまっていく | しま模様のバーが伸びる | Stripe |
| ×・ハンコ | 斜めにドン＋揺れる | Stamp |
| チェックリスト | 1行ずつ✓が入る | check / CheckLine |
| 章の扉 | 番号＋名前→ぼかして消える | Door |

## H. 密度
- **1〜2秒ごとに画面のどこかが変わる**（式が組み上がる・バーが伸びる・カードが足される）。止まった画面を作らない
- カード＝アイコン＋小見出し＋大きな数字。太い枠より「影＋薄い枠」、大事な数字は色で光らせる
