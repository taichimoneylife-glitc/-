# 年収の壁(2026)｜アフレコ読み上げ用（清書・v12／車・投資基準でタイト化）

> 基準：標準40〜65字／山場でも75〜90字／締め20〜35字／1パート1〜2文(山場3文)／6字/秒。
> 車リール・投資三大原則の実測に合わせて削った版。言い回し・数字はそのまま、尺だけ基準内に。

【フック】（約40字）
年収の壁、また変わったの知ってますか？「178万に上がった」って喜ぶ人、ちょっと待ってください。

【① 全体像】（約58字）
壁はぜんぶで4つ。住民税119万、扶養136万、所得税178万、そして社会保険130万。でも、本当に大事なのは1つだけなんです。

【② 税金（怖くない）】（約52字）
まず税金。所得税は178万まで、住民税は119万から。でも超えても少し増えるだけで、手取りが逆転することはありません。

【③ 扶養（怖くない）】（約48字）
次に扶養。これは夫の税金の話で、136万を超えても169万までは控除は満額。大きくは減りません。

【④ ★社会保険（山場）】（約88字・3文）
本命は、社会保険です。106万の壁は10月に消えて、今は51人以上の会社で週20時間働けば加入。130万を超えると扶養も外れて、国民年金や国保を自分で払うから、保険料で手取りがガクッと減るんです。

【⑤ とはいえ（メリット）】（約46字）
とはいえ、入れば年金は増えるし、病気や出産の手当ももらえる。国保にはない保障なんです。

【⑥ まとめ】※太一さんコピー
まとめると、こんな感じです。
51人以上の会社などでは、週20時間以上働くと社会保険に加入。
119万円を超えると、住民税がかかり始める目安。
130万円を超えると、旦那さんの社会保険の扶養から外れる。
169万円までは、条件を満たせば夫の配偶者控除・配偶者特別控除は満額。
そして178万円を超えると、本人の所得税がかかり始めます。
ただ、この中で特に気をつけたいのが「社会保険」。
税金は超えた分に少しずつかかりますが、社会保険は保険料の負担が発生することで、手取りが大きく変わる可能性があります。

【⑦ やることは2つ】（約66字）
やることは2つ。勤め先で社保に入る条件を確認する。そして超えるなら、手取りがしっかり増えるところまで働く。壁を避けるより、世帯の手取りと保障で決めましょう。

【締め】（約28字）
制度はまた変わります。気になる人は、プロフから相談してくださいね。
