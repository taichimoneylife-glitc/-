## STEP1 全体解析（参考）
- 尺59.8s／30fps／9:16（720×1280）。構成＝実写Bロール(0–10s)→**方眼紙図解(10.5–56s)**→実写Bロール+フォローCTA(56–60s)。
- 図解部は「資産形成は4つの力」→①節約②貯める③増やす④稼ぐ→4つを回す（サイクル図）。**番号付きの章立て**。
- テンポ：**0.6〜1.5秒ごとに要素が1つ増える**。1章≈6〜8秒で4〜6要素が積み上がる。章が変わると**画面を全消し→番号バッジから再ビルド**。
- 情報密度は中。1画面に「見出し＋ステッカー2〜4＋ラベル＋スタンプ/補足1」まで。詰め込まない。
- テイスト＝**紙の方眼ノート＋シール（ステッカー）を貼っていく**手作り感。AI風グラデ・光沢なし。

## STEP3 レイアウト（画面比%）
- 見出し行 Y≈19%：赤丸バッジ X≈17%／見出し中央 X≈47%／キャラ X≈84%（幅≈14%）。
- 図解ゾーン Y≈30〜62%：ステッカーは**左右2列**（中心 X≈27%と73%）、間に紺矢印。ラベルピルはステッカー直下。
- 補足ピル・スタンプ Y≈60〜70%。
- 下テロップ Y≈79%（中央）。※当方はInstagram下UI回避のため Y≈73%（y≈1400/1920）に置く。
- 余白：左右5%。要素は大きめ（ステッカー幅≈20%）。

## STEP4 図解の型
- 番号章立て（①〜④）／**フロー（A→B 矢印）**／Before-After（✕灰ピル→赤）／スタンプで結論強調／最後は**サイクル図**（4ステッカーを円配置＋赤い曲線矢印）。
- 理解のさせ方＝「ステッカー（モノ）＋ピル（行動）」の対で1概念。矢印で因果。スタンプで“ここ大事”。

## STEP5 アニメーション（秒で規定）
| 種類 | 内容 | 所要 |
|---|---|---|
| 見出しワイプ | clip 左→右 | 0.13–0.17s、直後に赤下線が左→右 0.2s |
| ステッカー着地 | scale 0.55→1.06→1.0、rotate ±15°→0、opacity 0→1 | 0.23s（オーバーシュート1回） |
| 矢印 | 線が左→右に描画→先端三角 | 0.1–0.13s |
| スタンプ | scale 1.6→1.0、rotate −8°固定、opacity 0→1（ドン） | 0.1–0.13s |
| ピル | scale 0.7→1.0 | 0.13s |
| 下テロップ | 語の塊でハードカット | 0s |
| 章替え | 全消し（ハードカット） | 0s |
| キャラ | 常時ゆっくり上下2px＋章ごとに表情差し替え | 常時 |
着地後のステッカーは**静止**（ふわふわさせない）。動くのは新しく出る要素だけ＝視線が迷わない。

## STEP6 出現順（視線誘導）
バッジ（既に在る）→見出し→**左ステッカー＋ピル→矢印→右ステッカー＋ピル→スタンプ→補足**。必ず左→右、上→下。同時出現なし。

## STEP7 音声同期
- 下テロップ＝ナレーションの語の塊（6〜10字）を**話した瞬間に**切替。
- ステッカーは対応する名詞を**言う瞬間（同時〜0.1s前）**に着地。スタンプは結論語の頭。

## マイルへの置換設計（STEP9）
章立て（番号は“仕組みの手順”にだけ使う）：
- **S1 マイルとは（0–5.1s）**：見出し「マイルとは？」→✈️ステッカー＋紺ピル「航空券に交換できるポイント」→灰ピル「飛行機に乗らなくても」→🧾生活費→矢印→🎫マイル＋赤スタンプ「生活費で貯まる」。
- **S2 貯まる仕組み（5.1–19.7s）**：見出し「貯まる仕組み」。**蛇行フロー（2列×3段）**で①生活費→②クレカ→（下）③入会キャンペーン→④ポイント→（下）⑤マイル→⑥特典航空券。各ステップに小さな番号バッジ。最後に赤スタンプ「家族の飛行機代を大幅カット」。
- **S3 条件（19.7–35.3s）**：見出し「ただし条件あり」（キャラ困り顔）。📅＋特大数字「半年で100万円」→矢印→紺ピル「月 約17万円」→🏠「固定費をまとめる」／🛒「大きな出費」＋赤スタンプ「チャンス」→紺ピル「他にも方法あり」→📱「気になる方はDM」赤ピル。
- **S4 お得だけじゃない（35.3–50.0s）**：見出し「お得だけじゃない」。灰ピル「飛行機代がお得」＋赤✕→👨‍👩‍👧‍👦家族ステッカー＋赤ピル「子どもが小さい今」→紺ピル「思い出・経験」→🐷「将来の備え」⚖🎒「今しかできない経験」→赤スタンプ「同じくらい大切」。
- 全編：下テロップ（語の塊）＋右上キャラ（表情：笑顔→指差し→困り→手を振る）。
- イラストは当面**SVGステッカー（自作・同じ線/色ルール）**。生成画像が来たら同じ白フチ処理で差し替え。キャラは「太一ちびキャラ」生成待ち（当面SVG）。
