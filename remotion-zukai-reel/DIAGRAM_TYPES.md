# 図解の型カタログ（参考インプット）

出典：スライド図解まとめ記事（slideland229）。図解の"型"を使い分けるための知識ベース。
お題に対して「どの型が一番伝わるか」を選ぶために使う。

---

## 1. ツリー図（階層・グループ化）
- **形**：頂点から枝分かれ。各グループはヘッダー行に色（黄）を敷いて箱を束ねる。
- **強み**：階層構造が一目でわかる。複雑な要素を"グループ化"して整理できる。
- **弱み**：階層が深いとスペースを食い、見づらくなる。大規模構造の丸載せは不向き。
- **例**：組織図（CEO→本部→部）。
- **うちでの活用**：今の連結図解（見出し→箱→結論）はこのツリー型の一種。2〜3階層まで。

## 2. ピラミッド図（土台→上位概念）
- **形**：三角形に積み上げ。下＝土台、上＝上位概念/ゴール。頂点に「達成」等の吹き出し。
- **強み**：土台と上位の関係が直感的。形が明快でプレゼン向き。
- **弱み**：「上＝偉い/重要」と誤解されやすい。誤解を招く場面では避けるか意図を明記。
- **デザイン**：見出しに縦アクセントバー（▎）、リード文に赤の強調ワード＝**うちのスタイルと一致**。
- **うちでの活用**：「3要素が土台→ゴール達成」のような積み上げ構造のテーマに。

## 3. フロー図（横型）
- **形**：左→右に円（丸）を矢印でつなぐ。円は左→右で色が濃くなるグラデ。
- **強み**：左→右の自然な視線誘導で流れを追いやすい。横長スライドでスペース効率が良い。
- **弱み**：縦型リール(9:16)とは相性が悪い（横幅が足りない）。
- **例**：選考フロー（応募→面接→内定）。
- **うちでの活用**：リールは縦なので基本は縦型を使う。横型は3ステップ以内なら可。

## 4. フロー図（縦型）★リール向き
- **形**：上→下に STEP0, STEP1… と進む。各STEPに色付きバッジ＋見出し＋説明文。点線でつなぐ。
- **強み**：各ステップの詳細を書き込める。縦長でリールに最適。
- **例**：選考プロセス（STEP0 カジュアル面談 → … → JOIN!!）。
- **うちでの活用**：**手順・順序モノはこの型**。STEPバッジ（丸に番号/色分け）＋点線コネクタを
  うちの図解に取り入れると強い（今後の拡張候補）。

## 5. ビフォーアフター（対比）★比較に最強
- **形**：左右2カラム。ASIS（導入前＝暗い色）↔ TOBE（導入後＝アクセント色）で対比。
- **強み**：「前」と「後」のコントラストが一目。サービス紹介の定番。
- **コツ**：配色だけでなく**イラストのテイストまで差をつける**と説得力が上がる。
- **うちでの活用**：**「株 vs 債券」の値動き比較にこの型がドンピシャ**。
  - 株側＝暗め/不安色でギザギザ（乱高下）、債券側＝アクセント色でなめらか右肩上がり。
  - バッジ ✕（株）／◯（債券）で勝敗を明示。

---

## 6. マトリクス図（2軸4象限）
- **形**：縦軸・横軸を引いて4象限に分類・マッピング。
- **強み**：2つの評価軸での位置づけが一目（例：リスク×リターン）。
- **うちでの活用**：「株＝ハイリスク寄り／債券＝ローリスク・安定リターン」など投資商品の位置づけに。

## 7. サイクル図（循環）
- **形**：矢印で円環状につなぐ。終わりが始まりに戻る。
- **強み**：繰り返す仕組み・好循環を表せる。
- **うちでの活用**：「入金→運用→利益→再投資」の複利サイクル、資産形成の回るループに最適。

## 8. ファネル図（絞り込み）
- **形**：上が広く下に向かって狭くなる漏斗。各段の比例・階層関係。
- **強み**：段階的に絞られる流れ（母数→結果）を表現。
- **うちでの活用**：「収入→支出→残る額→投資に回せる額」の目減りを見せる時に。

## 9. ベン図（重なり・共通点）
- **形**：円を重ねて共通部分を示す（2〜4円）。
- **強み**：複数要素の重なり・違いを直感的に。
- **うちでの活用**：「安全性 ∩ 高利回り＝債券」など"おいしい重なり"を強調する時に。

## 10. 比較表（テーブル）
- **形**：行＝項目、列＝選択肢の表。◯✕△やハイライトで差を出す。
- **強み**：多項目の横並び比較に強い。
- **弱み**：情報過多・単調になりやすい（リールでは行を絞る）。
- **うちでの活用**：「現金一括／ローン＋運用」を3〜4項目で◯✕比較する時に。

## 11. 階段・ステップアップ図
- **形**：左下→右上へ段を上がる。積み上がる成長・手順。
- **強み**：右肩上がりの成長感・順を追う達成感。
- **うちでの活用**：「10年後に資産が段階的に増える」成長ストーリーに。

## 12. タイムライン／ロードマップ
- **形**：時間軸に沿って出来事・マイルストーンを配置。
- **うちでの活用**：「購入→10年運用→満期」の時間の流れを見せる時に。

## 型の選び方（早見）

| お題のタイプ | 使う型 |
| --- | --- |
| 全体像・分類・組織 | ツリー図 |
| 土台→ゴールの積み上げ | ピラミッド図 |
| 手順・順序（縦） | フロー図(縦)＋STEPバッジ |
| 2つの対比・前後比較 | ビフォーアフター（左右2カラム） |
| 因果・つながり | 連結図解（今のうちの基本形） |
| 2軸での位置づけ（リスク×リターン等） | マトリクス(4象限) |
| 繰り返す仕組み（複利・再投資） | サイクル図 |
| 段階的な絞り込み（収入→残る額） | ファネル図 |
| 重なり・共通点（安全∩高利回り） | ベン図 |
| 多項目の横並び比較 | 比較表（行を絞る） |
| 成長・時間の流れ | 階段／タイムライン |
