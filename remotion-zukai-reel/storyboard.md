# 設計書（storyboard）— 「500万円の車、どう買う？」

- 尺 70.10秒 ／ 1080×1920 ／ 30fps ／ 音声主役（話す瞬間に要素を出す）
- **テロップ＝あなたのナレーション文言そのまま**（改変しない）
- 図解要素＝Claudeが制御（カード/数字/比較/矢印/アイコン/ライン/吹き出し/ゲージ）
- 画像＝別AIで生成（`assets/image_brief.md`）→ `public/gen/` に配置
- 効果音＝自動（pop=カード出現／whoosh=スライド・転換／tick=カウント／ding=強調／success=締め）

凡例：📷=画像スロット ／ 🔢=数字カウント ／ 🟦=カード ／ ⇄=比較 ／ ➡=矢印 ／ ✓✗=マーク ／ 🔊=効果音

---

## 1枚目（0.0–7.0s）現金一括かローンか → 結論
- ナレ：例えば500万円の車。買い方は現金一括か、銀行ローンか。結論僕はあえてローンで買います。
- テロップ：**500万円の車、どう買う？** → **現金一括／銀行ローン** → **結論 あえてローン**
- 図解：📷`s1_car.png`（中央上）／🟦カード「支払い方法」＝現金一括 ｜ 銀行ローン（ローンに✓）／結論はマーカー蛍光
- 動き：タイトルfadein → カード⇄スライドイン🔊whoosh → 結論ポップ🔊ding
- 画像：`s1_car.png`

## 2枚目（7.0–21.0s）総支払550万 → 元手の使い方
- ナレ：金利2%で10年で組むと車両価格は500万円　利息はおよそ50万　総支払額は約550万。利息の50万円は損って思うかもしれないけど、問題はここからの元手の資金の使い方。
- テロップ：**金利2%・10年** → 車両**500万** ＋利息**約50万** ＝ 総支払**約550万** → **利息50万は損？** → **問題は"元手"の資金の使い方**
- 図解：🟦カード「総支払の内訳」＝車両🔢500 / 利息🔢50(赤) / 総支払🔢550(強調ハイライト)／後半は文字転換
- 動き：数字を順にカウント🔊tick → 総支払を強調🔊ding → 「損？」提示 → 「元手の使い方」へ視線移動
- 画像：`s2_wallet.png`（内訳カードの横 or 下）

## 3枚目（21.0–33.0s）運用は株か債券か → 債券
- ナレ：僕なら元手の500万を運用に回します。なにで運用するかが重要で、株か債券なのか？僕はここではリスクを取りたくないので、安定的な運用ができる債券を選びます。
- テロップ：**元手500万を運用に回す** → **株？／債券？** → **リスクを取りたくない** → **安定的な運用ができる債券**
- 図解：➡「元手500万→運用」／⇄比較 株📷`s3_stock.png`(乱高下) vs 債券📷`s3_bond.png`(安定上昇)／株に✗、債券に✓
- 動き：矢印が伸びる🔊whoosh → 株/債券を左右スライド🔊whoosh → 債券に✓ポップ🔊ding
- 画像：`s3_stock.png` / `s3_bond.png`

## 4枚目（33.0–53.0s）子育て世帯こそ計画的 → 米国債5%
- ナレ：子育て世帯は特に・教育資金・老後資金・その他特別費用の備えなどを計画的にしないといけない。株は暴落のリスクもあるけど、債券は数年後にいくらになるか原則約束された資産だから計画的。しかも今米国債なら金利は約5%と高水準。実際に僕も5%超えの債券を保有してます。
- テロップ：**子育て世帯こそ"計画的に"** → 🎓教育資金／🐖老後資金／⭐その他特別費用 → **株は暴落リスク／債券は約束された資産** → **米国債は金利 約5%（高水準）** → **僕も5%超えの債券を保有**
- 図解：アイコン3枚を順次出現／⇄株✗ vs 債券✓／米国債は🔢5%を大きくカウント＋横ゲージ「0%→高水準」／📷`s4_usa.png`
- 動き：アイコン順次🔊pop×3 → 比較 → 5%カウント🔊tick→ding → ゲージ伸び🔊whoosh
- 画像：`s4_family.png`（前半・子育て）／`s4_usa.png`（後半・米国債）

## 5枚目（53.0–70.1s）10年後の比較 → トータルで得
- ナレ：では10年後どうなるのか？債券で運用すると約810万　車の総支払額550万を引いても約260万円のプラス。利息50万を払っても、運用益260万の方が大きい。だから長期的に見るとトータルで得ということです。
- テロップ：**10年後どうなる？** → 債券運用**約810万** － 車**550万** ＝ **＋約260万** → **利息50万 ＜ 運用益260万** → **トータルで得**
- 図解：🟦カード「10年後の資産」＝債券運用🔢810 / 車550 / 差分🔢+260(強調)／横ゲージ 車550→運用810／締めは「得」マーカー
- 動き：カード出現🔊pop → 数字カウント🔊tick → 差分強調🔊ding → 「トータルで得」ポップ🔊success
- 画像：`s5_growth.png`（10年後）／`s5_trophy.png`（締め）
