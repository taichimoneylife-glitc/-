# 図解動画の台本テンプレート

このフォーマットで台本を書いて渡してもらえれば、そのまま動画化できます。
**1シーン＝1メッセージ**が最大のコツ。詰め込まず、テンポで見せます。

## ■ 構成（上から順に流れます）

### 0. つかみ（Intro）
- メインテロップ：「__________」（例：教育費、結局いくら必要？）
- サブ：「__________」（例：3つのステップで解説）

### 1〜N. 各ポイント（← 必要な数だけ繰り返す）
1つのポイントにつき、次の4つを埋めるだけ：

- **見出し**（12文字以内・言い切り）：「__________」
- **図解の中身**（どれか）：
  - アイコン指定：スマホ / 値札 / カート / 金庫 / 顔 / カレンダー / グラフ …（無ければ「おまかせ」）
  - or 数字ノード：①②③ など
- **吹き出し/強調ワード**（任意）：「__________」
- **下の帯コメント**（20文字前後・補足）：「__________」

### （任意）全体像（マインドマップ）
関係性を見せたいときに。中心から線が伸びて枝が順番に出ます。
- 中心ノード：「__________」
- 枝：①「____」 ②「____」 ③「____」 ④「____」

### 最後. まとめ（Outro）
- 見出し：「__________」（例：まずは証券口座から）
- おさらい（各ポイントを一言で）：①____ ②____ ③____ ④____
- CTA：「__________」
- 注意書き（任意）：「__________」（例：※投資判断はご自身の責任で）

## ■ うまくいくコツ（これを守ると綺麗に決まる）

1. **1シーン1メッセージ**：言いたいことが2つあるなら2シーンに分ける
2. **見出しは短く言い切る**：「安いから買う」〇 /「安いと感じてしまい買ってしまうこと」✕
3. **数字を入れる**：「年360万」「1,800万」など具体数字は図解と相性抜群
4. **専門用語はかみ砕く**：初見の人が分かる言葉に
5. **帯コメントは"理由・補足"**：見出しの言い換えではなく一歩踏み込む
6. **CTAは最後に1つだけ**

## ■ 記入例（このまま動画化できるレベル）

**基本設定**：タイトル=「子どもの教育資金、新NISAでどう準備する？」／尺=約40秒／9:16／カラー=青系／実写つかみ=あり／切替=スライド／CTA=保存＆フォロー

**0. つかみ**
- メイン：「子どもの教育費、どう貯める？」
- サブ：「3つのステップで解説」

**1. そもそも、いくら必要？**
- 見出し：「大学まで約1,000万円」
- 図解：グラフ（右肩上がり）
- 帯：進学プランで幅は出るが“長期で準備”が基本

**2. どうやって準備する？**
- 見出し：「新NISAでコツコツ積立」
- 図解：カレンダー＋積み上がる棒
- 吹き出し：「毎月1〜3万」
- 帯：時間を味方に。早く始めるほど複利が効く

**3. 注意点は？**
- 見出し：「使う時期に“取り崩し”設計」
- 図解：金庫＋矢印
- 帯：暴落中に使う事態を避け、数年前から現金化

**全体像（マインドマップ）**
- 中心：「教育資金 × 新NISA」
- 枝：①必要額 ②積立 ③注意点

**まとめ**
- 見出し：「まずは毎月の積立額を決める」
- おさらい：①約1,000万 ②新NISAで積立 ③取り崩し設計
- CTA：保存＆フォローで続きを
- 注意書き：※投資判断はご自身の責任で
