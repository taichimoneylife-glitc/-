# 図解リールの台本テンプレート（連結図解・ページ方式）

このフォーマットで **「1枚目・2枚目・3枚目…」** と埋めて渡してもらえれば、
そのまま連結図解リール（箱を線でつないで1画面に組み上げるアニメ）にします。

- **1ページ＝1メッセージ**。詰め込まず、線でつなぎながらテンポで見せます。
- 各ページの要素は下の「スロット」に順番に出現します（見出し→箱→結論→数字→注記→帯）。
- 書いた項目だけ表示されます。**使わないスロットは空欄でOK**（自動で詰めます）。
- ページ切替は「下から上へシュッ」で統一。文字の大きさ・配置・色は毎回同じ基準（`DESIGN_RULES.md`）。

---

## ■ 全体設定（最初に一度だけ）

| 項目 | 例 | あなたの指定 |
| --- | --- | --- |
| テーマ／タイトル | 500万円の車、現金 vs ローン |  |
| ページ数 | 6枚 |  |
| CTA（最後の誘導） | 本文にまとめ／保存＆フォロー |  |
| 特記事項（任意） | 数字はこの値で固定、など |  |

※ 色・尺・切替・文字サイズなどの見た目は `DESIGN_RULES.md` で固定済み。
　変えたいときだけここに書く（例：「今回だけアクセントを青に」）。

---

## ■ 各ページのフォーマット（この6項目を埋めるだけ）

各スロットの意味：

| スロット | 役割 | 目安 |
| --- | --- | --- |
| **見出し** | 枠付きタイトル（そのページの問い・テーマ） | 12〜18文字・言い切り |
| **サブ見出し**（任意） | 見出しの補足（条件など） | 短く |
| **箱**（0〜2個） | 比較・要素。線でつながって出る | ラベルは短く（例「利息 50万」） |
| **結論**（任意） | 箱の下に出る大きい結論文 | 赤字にしたい語は `**赤**` |
| **特大数字**（任意） | 赤い特大の数字（増減・金額） | 「＋約260万円」など |
| **注記**（任意） | グレーの小さい補足 | ※で始める |
| **帯**（任意） | 紺色の帯に白文字 | そのページの持ち帰り |
| **締めの一文**（任意） | 帯の下の一言（紺文字・箱なし） | ダメ押しの一言 |

箱の書き方（1個 or 2個）：
`ラベル | 色(標準/赤/紺) | サブ(任意) | バッジ(◯/✕/なし)`
- 色：標準＝白枠、赤＝赤ベタ、紺＝紺ベタ
- バッジ：◯＝緑チェック、✕＝赤バツ（良い/悪いを示すとき）

### 記入例（1ページぶん）

```
# 1枚目
見出し：500万円の車、どう買う？
サブ：現金一括 vs 銀行ローン
箱1：現金一括 | 標準
箱2：銀行ローン | 赤
結論：トータルで **得** なのは？
帯：答え → ローンを組んで運用
```

```
# 4枚目
見出し：なぜ株じゃなく“債券”？
箱1：株 | 標準 | 暴落もある＝不確定 | ✕
箱2：債券 | 標準 | 10年後を“確定”できる | ◯
結論：**確実に** 増やして残す
注記：※子育て世帯は教育・老後資金を計画的に
```

```
# 5枚目
見出し：10年後、どうなる？
箱1：債券で 約810万 | 紺
結論：− 総支払 **約550万**
特大数字：＝ ＋約260万円
帯：利息 約50万 ＜ 運用益 約260万
```

## ■ きれいに決まるコツ

1. **1ページ1メッセージ**：言いたいことが2つあるなら2ページに分ける
2. **見出しは短く言い切る**：問い or 結論のどちらか
3. **箱のラベルは短く**（画面幅の都合。長いと折り返す→「総支払 550万」くらい）
4. **数字は具体的に**：「利息50万」「＋260万」など。図解と相性抜群
5. **赤字は"ここだけ"**：結論の一番効かせたい語だけ `**…**` で赤に
6. **帯は"持ち帰り"**：見出しの言い換えではなく、そのページの結論を一言で
7. **最後のページ**は必ず「結論＋CTA（帯）」で締める
