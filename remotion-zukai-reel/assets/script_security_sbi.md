# 台本たたき台：SBI証券編（約70〜80秒）「口座の戸締まり」
2026年10月 ／ 中身はすべてSBI証券の公式ページで確認済み（⚠️の所だけ、収録前に実際の画面で確認）
※たいちさんの言葉に直して使ってください。

---

【冒頭】
SBI証券を使っている人。
パスキーを設定しても、実は古いパスワードという「合鍵」が残ったままかもしれません。
証券口座を家にたとえて、戸締まりを4つ確認していきます。

【① 玄関の鍵】
1つ目は玄関の鍵。
パスキーを設定しても、ユーザーネームとパスワードでのログインは残ったままです。
そこで「ログインパスワード無効設定」を有効にすると、
パスキーでしかログインできなくなります。
場所は「My設定」の「各種サービス」から「セキュリティ関連」。
ログインの設定はここにまとまっています。

【② 勝手口】
2つ目は勝手口。
SBI証券には、米国株アプリやFXアプリ、パソコン用のツールなど、入口がたくさんあります。
「アプリ・ツールのログイン制限設定」で、
使わないアプリからのログインを1つずつ止められます。
ちなみに、2026年7月10日以降は、
1つ目のパスワード無効を有効にすると、この制限も自動でかかります。

【③ 金庫】
3つ目は金庫。
使っていない商品の取引そのものを止めることもできます。
公式のよくある質問「不正なアクセスを防止するための対策」にある
「取引制限受付フォーム」から申し込みます。
外国株やFXなど、自分が使わないものを選んでください。

【④ 留守の間の戸締まり】
4つ目は、留守の間の戸締まり。
「ログイン一時利用停止設定」をすると、
WEBもアプリもツールも、全部のログインを止められます。
それでも、設定済みの投資信託の積立は原則続きます。
ただし、自分もログインできなくなるのと、
「重要なお知らせ」を確認していないと注文が止まることがあるので、
ほとんどログインしない、積立中心の人向けです。

【おまけ：防犯カメラ】
最後に、ログイン通知メールとログイン履歴で、
知らないログインがないか、ときどきチェックしておくと安心です。

【締め】
鍵、勝手口、金庫、留守の戸締まり。
保存して、今日のうちに確認しておきましょう。

## 画面で見せる所（公式ページに画面あり＝描き直して使う）
- 「セキュリティ関連」の画面：パスキー認証／デバイス認証／FIDO（スマホ認証）／電話番号認証／ログイン一時利用停止設定／アプリ・ツールのログイン制限設定が「設定済／未設定」＋「変更」で並ぶ
  → 1つずつ**寄って、その行だけ明るく**（家の鍵・勝手口・留守…と対応させる）
- 場所：ログイン後のTOPページの「セキュリティ設定」リンク、または My設定 → 各種サービス → セキュリティ関連（公式FAQで確認）
- アプリ・ツールのログイン制限の表：SBI証券Plus、国内株アプリ、投信積立アプリ、米国株アプリ、FXアプリ、先物・オプションアプリ、取引所CFDアプリ、HYPER SBI 2、HYPER SBI FX
- 取引制限受付フォーム（公式FAQからのリンク）

## 公式で確定したこと（前回の⚠️が解消）
- ログイン一時利用停止の**解除**は、公式の「各種制限設定」ページの「ログイン一時利用停止設定解除」ボタンから（モバイルサイトの解除ページに進む）

## ⚠️ 収録前に画面で確認
- 「外国株を買ったことがなくても外国株式の取引口座が開設されている場合がある」→ 台本には入れていない
- 取引制限受付フォームで選べる商品の一覧と、投信積立への影響
