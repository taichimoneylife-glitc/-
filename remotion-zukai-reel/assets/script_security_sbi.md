# 台本たたき台：SBI証券編（約60〜70秒）
2026年10月 ／ 中身はすべてSBI証券の公式ページで確認済み（⚠️の所だけ、収録前に実際の画面で確認）
※たいちさんの言葉に直して使ってください。

---

【冒頭】
SBI証券を使っている人、
パスキーを設定したから安心…と思っていませんか？
実は、まだやっておきたい設定が4つあります。

【① パスワードでのログインを止める】
1つ目は、パスワードでのログインを止めること。
パスキーを設定しても、
ユーザーネームとパスワードでのログインはそのまま残っています。
「ログインパスワード無効設定」を有効にすると、
パスキーでしかログインできなくなります。
場所は「My設定」→「各種サービス」→「セキュリティ関連」です。

【② 使わないアプリのログインを止める】
2つ目は、使わないアプリのログインを止めること。
米国株アプリやFXアプリなど、
使っていないアプリからもログインできる状態になっています。
「アプリ・ツールのログイン制限設定」で、
使わないアプリを選んで止められます。
2026年7月10日以降は、1つ目を有効にすると、これも自動でかかります。

【③ 使わない取引を止める】
3つ目は、使わない取引を止めること。
外国株やFXなど、自分が使っていない取引は、
「取引制限受付フォーム」から止める申し込みができます。
フォームは、公式のよくある質問
「不正なアクセスを防止するための対策」の中にあります。

【④ ログインを一時停止する】
4つ目は、ログインそのものを一時停止すること。
「ログイン一時利用停止設定」をすると、
WEBもアプリも、全部のログインが止まります。
それでも、設定済みの投資信託の積立は原則続きます。
ただし、自分もログインできなくなるのと、
「重要なお知らせ」を確認していないと注文が止まることがあるので、
ほとんどログインしない、積立だけの人向けです。

【締め】
あわせて、ログイン通知メールもオンにしておくと、
知らないログインにすぐ気づけます。
保存して、今日のうちに確認しておきましょう。

## 画面で見せる所（公式ページに画面あり＝描き直して使う）
- 「セキュリティ関連」の画面：パスキー認証／デバイス認証／FIDO（スマホ認証）／電話番号認証／ログイン一時利用停止設定／アプリ・ツールのログイン制限設定が「設定済／未設定」＋「変更」で並ぶ → 話している設定の行に寄って、そこだけ明るく
- 場所：ログイン後のTOPページの「セキュリティ設定」リンク、または My設定 → 各種サービス → セキュリティ関連（公式FAQで確認）
- アプリ・ツールのログイン制限の表：SBI証券Plus、国内株アプリ、投信積立アプリ、米国株アプリ、FXアプリ、先物・オプションアプリ、取引所CFDアプリ、HYPER SBI 2、HYPER SBI FX
- 取引制限受付フォーム（公式FAQからのリンク）

## 公式で確定したこと
- ログイン一時利用停止の解除は、公式の「各種制限設定」ページの「ログイン一時利用停止設定解除」ボタンから

## ⚠️ 収録前に画面で確認
- 取引制限受付フォームで選べる商品の一覧と、投信積立への影響
- ログイン通知メールの設定場所（公式では「ログイン履歴サービス」のページから利用する、という書き方）
