# 子どもNISAリール｜図解の絵コンテと画像指示書（v2・18枚）2026-11-17

台本：assets/script_kodomo_nisa.md（確定版）／事実：.claude/skills/zukai-reel/references/facts-kodomo-nisa.md

## 考え方
- テーマは「子どものお金」。教育資金の話は④だけ。全体を通して「子どものお金」を主役にする。
- 色：子どもNISA＝緑、親（大人）のNISA＝オレンジ。最後まで固定。
- 数字・表・矢印・グラフは動画側で描く。画像は「人」と「実物の小物」だけ。
- 動き：参考⑫の部品（src/components/flowKit.tsx）。図解パートは1本の線でつながる長い図をカメラが下へ追う。見た目はいつものノート。

## 絵コンテ
**① 結論**
- 真ん中に「子どものお金として使うもの」（大見出し・流れ込んでピントが合う）。
- 子どもが自分の貯金箱を大事そうに抱える絵（kn_child_hug_piggy）。左右に家族（kn_family_baby）。

**② 概要**
1. 大人の新NISA＝**縦に積んだ箱2つ**（下に「600万円」の緑の箱、上に「1,200万円」のオレンジの箱。合わせて1,800万円）。
2. 「600万円分の積立枠を」で下の600万円の箱が光る → 箱が左へすべり出て、横の時間の棒「0歳〜17歳」の上に乗る（ラベル「0歳から先に使える」）。
3. 「18歳になると」→ 棒の右端から、600万円の箱が元の場所へ戻る矢印。
4. そのまま**全体像の表**がパッと出る（1行ずつ0.1秒おきに）：
   | 項目 | 子どもNISA |
   |---|---|
   | 始まる | 2027年1月 |
   | 対象年齢 | 0〜17歳 |
   | 年間投資枠 | 60万円（月5万円） |
   | 非課税保有限度額 | 600万円 |
   | 買い方 | 積立のみ |
   | 口座 | 子どもの名義・管理は親 |
   | 引き出し | 12歳まで原則 ✕／12歳〜 子どもの同意が必要 |
   小さい字：※600万円は大人の1,800万円の中に含まれる予定です（別に増えるわけではありません）
   画像：表の横に赤ちゃんと親（kn_family_baby）。

**③ デメリット3つ（表のアップで解説）**
- カメラが表の「引き出し」の行にズーム → 赤い手書きの丸。
  - 「12歳までは原則引き出せない」→ 鍵のかかった貯金箱（kn_piggy_locked）＋ランドセルの小学生（kn_kid_elementary）。
  - 「12歳を過ぎても子どもの同意が必要」→ 親が中学生の子に書類を見せて相談し、子どもがサインする（kn_parent_ask_teen → kn_teen_sign）。
- カメラが「買い方：積立のみ」の行へ横にすべる → 赤い丸。
  - 「お祝いやお年玉を一部入れたくても一括では入れられない」→ お年玉袋（kn_otoshidama）とご祝儀袋（kn_gift_envelope）が貯金箱に入ろうとして「一括 ✕」で跳ね返る → 小さなコインに分かれて、1枚ずつ入っていく（kn_coin を動画側でくり返す）。

**④ 教育資金は？**
- 「なんでこんなに縛りが多いかっていうと」→ カメラが③の表の行へ一瞬戻って光る枠 → また戻る（回想の往復）。
- 「子どものお金だから、親が自由に引き出せない」→ 親が子どもの貯金箱を開けようとして、鍵で開かず困る（kn_parent_cant_open）。
- 「教育資金って、出すのは親」→ 学費のイメージ（kn_school_items）が、オレンジの「親のNISA」（kn_parent_phone_nisa）の方へ移る。ハンコ「教育資金は まず親のNISA」。

**⑤ じゃあ何に使う？**
- 「子どもの将来の選択肢を広げるお金」→ 子どもの将来が吹き出しで4つ（kn_dream_study_abroad／kn_dream_sports／kn_dream_job／kn_dream_wedding）。
- 「コツコツ積み立てておいてあげる」→ 親が眠る子どもを見ながら将来を考える（kn_parent_watch_sleeping）＋時間の棒「0歳→18歳」の上で**コインが1枚ずつ積み上がる**（kn_coin をくり返し落とす）。メーターが段で上がる：元本 約108万円 → 年5%なら約175万円。
- 「将来子どもに渡してあげるイメージ」〜「実際に増えた画面を見せて」→ 親と高校生の子が並んでパソコンを見て、株が上がっている様子に笑顔（kn_family_pc_rising）。パソコンの画面の横に動画側で「積み立てた額 → いまの額」。
- 最後に①〜⑤の引きの全体図（約0.6倍）。

**締め**：いつものTapCard（プロフ → 公式LINE → ここからお受け取りください）。

## 作ってほしい画像（18枚）
```
【共通スタイル】※毎回この文と、太一の画像（基準）を添付する
添付画像のキャラクターと同じ絵柄で描いてください。
茶色の細い輪郭線、やわらかいパステル調の塗り、軽い陰影、ほんのり紙の質感。
線の太さ・色の明るさ・塗り方は添付画像とそろえる。
透過PNG（背景なし）、正方形、被写体は中央で余白多め。
文字・数字・ロゴ・企業名は入れない。
1枚ずつ別の画像として出す（1枚に複数を並べない）。
親は20代後半の夫婦、子どもは同じ子を年齢違いで描く（性別がわかりにくい服装・同じ髪型と服の色＝緑系）。

【人】
1.  kn_family_baby          → 若い夫婦が赤ちゃんを抱いて笑顔、全身
2.  kn_child_hug_piggy      → 5歳くらいの子どもが緑の貯金箱を両手で大事そうに抱える、全身、うれしそう
3.  kn_kid_elementary       → ランドセルを背負った小学生（8歳くらい）、全身、笑顔
4.  kn_parent_ask_teen      → 親が中学生（13歳くらい）の子に1枚の書類を見せて話している、2人とも上半身、おだやか
5.  kn_teen_sign            → 中学生の子が机でペンを持って書類にサインしている、上半身、まじめな表情
6.  kn_parent_cant_open     → 親が鍵のかかった緑の貯金箱を開けようとして開かず、困った顔、上半身
7.  kn_parent_watch_sleeping→ 夜、親が布団で眠る赤ちゃんを見守りながら、将来を考えている優しい表情、全身
8.  kn_family_pc_rising     → 親と高校生の子が並んでノートパソコンを見ている。画面に右上がりのグラフ（文字なし）。2人ともうれしそうな笑顔、上半身
9.  kn_dream_wedding        → 大人になった子の結婚式（タキシードとドレスの2人、笑顔）、全身
10. kn_dream_study_abroad   → 大学生くらいの子がスーツケースを持って空港で笑顔（留学の夢）、全身
11. kn_dream_sports         → 高校生くらいの子がスポーツ（サッカーなど）を楽しんでいる、全身
12. kn_dream_job            → 若い大人になった子が好きな仕事（パソコンやデザイン）をしている、上半身

【小物】
13. kn_piggy_locked         → 緑の貯金箱に、大きな南京錠と鎖がかかっている
14. kn_otoshidama           → お年玉袋（かわいい柄、文字なし）
15. kn_gift_envelope        → お祝いのご祝儀袋（紅白の水引、文字なし）
16. kn_coin                 → 金色のコイン1枚（正面、少し斜め。くり返し落として積み上げに使う）
17. kn_school_items         → 学費のイメージ：教科書・ノート・卒業の帽子をまとめた小物
18. kn_coin_stack          → 金色のコインが何段にも積み上がった山（積立が育ったイメージ）
```

## 追加の画像（v3・台本 v2 に合わせて 2026-11-18）

```
（共通スタイルは上と同じ）
19. kn_parent_phone_nisa   → 親（20代後半）がスマホを見ている。画面に右上がりのグラフ（文字なし）、オレンジの服、上半身、落ち着いた表情
20. kn_handover_18         → 親が18歳くらいの子に、緑の通帳（文字なし）を両手で手渡している。2人とも笑顔、上半身
21. kn_parent_kid_phone    → 親と小学生（10歳くらい）の子がソファで並んで、スマホの画面（右上がりのグラフ）を一緒に見て話している、上半身
22. kn_kid_surprised_grow  → 小学生の子が、目を輝かせて「すごい！」という表情、上半身
23. kn_parent_school_pay   → 親が学校の書類（文字なし）を見ながら電卓をたたく、上半身（「教育資金を出すのは親」）
```
