# 台本：アメックスポイントの使い方（サクッと版）
2026年10月31日 アメックス公式ページで確認（research_amex_points.md）
※台本は短く。細かい数字・条件は【図解】で見せる。数字はメンバーシップ・リワード・プラス未登録の場合。

アメックス使ってる人
そのポイントの使い方、損してます

せっかく貯めたアメックスポイント
使い方を間違えると、10,000ポイントが3,000円分になることも
　【図解】10,000ポイントのコインの山 → 縮んで「3,000円」

1ポイント＝1円以下になる使い方まとめたから
損してないか確認してね
　【図解】4つの項目のリスト（1ポイント＝0.3円などの値札）

①カードの支払いに充当する
ネットショッピングでこの画面が出たら要注意
間違って押すと、10,000ポイントが3,000円分になるよ
　【図解】「ポイントを使う」画面 → 押した後はキャンセル不可・返品してもポイントは戻らない（公式）

②Amazonでポイント払いする
Amazonの支払いでアメックスのポイントを使うと
10,000ポイントが3,000円分にしかならないよ
　【図解】Amazonのレジ → 1pt＝0.3円の値札

③ほかのポイントやマイルに交換する
楽天ポイントやJALマイルに交換すると
10,000ポイントが3,000〜3,300ポイントにしかならないよ
　【図解】交換先ごとの「10,000ポイントが何になるか」の棒グラフ（プラス未登録）
　　楽天ポイント 3,000 ／ JALマイル 約3,333 ／ Marriott 4,950 ／ その他の航空会社 5,000マイル ／ ANAマイル 5,000マイル ／ ヒルトン 6,250
　　→ プラス登録済みだと：楽天 約4,667 ／ JAL 4,000 ／ ANA 10,000 ／ ヒルトン 12,500（伸びる棒で見せる）

④有効期限を放置する
ポイントの有効期限は最長3年
使わずに放っておくと、消えてしまうこともあるよ
　【図解】カレンダー3年 → ポイントが消える／一度でも交換すれば無期限（公式）
