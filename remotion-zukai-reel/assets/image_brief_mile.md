# マイルリール｜画像指示書 v2（方眼紙×ステッカー図解用）2026-10-16

> デザインは `mile_sticker_design_spec.md`。今は自作SVGステッカーで仮組み済み（`src/components/stickers.tsx`）。
> 生成画像を `public/gen/<名前>.png` に置けば、`<Sticker img="名前">` で**同じ白フチ＋影のまま差し替わる**。
> 白フチ・影はこちらで付けるので、画像側は**白フチなし・透過PNG**で。

## ■ まとめて1ブロックでコピペ → 一括生成
```
【共通スタイル】
フラットなイラスト、太めの濃い紺色の輪郭線、ステッカーのような可愛いアイコン調、
透過PNG、正方形、被写体は中央で余白多め、文字やロゴは入れない、影やグラデは控えめ、
白フチは付けない（後で付けます）。色は自然でOK。

【小物】
1.  mile_plane     → 旅客機を斜め上から見た図
2.  mile_receipt   → 毎月の生活費を表すレシート（下がギザギザ）
3.  mile_card      → 無地のゴールドのクレジットカード（ブランド名なし）
4.  mile_gift      → 入会キャンペーンの特典を表すリボン付きプレゼント箱
5.  mile_coins     → 積み上がったポイントのコイン
6.  mile_ticket    → 特典航空券（搭乗券）
7.  mile_house     → 毎月の固定費を表す家
8.  mile_cart      → 大きな買い物を表すショッピングカート
9.  mile_calendar  → 半年を表すカレンダー
10. mile_phone_dm  → 吹き出し（DM）が出ているスマホ
11. mile_piggy     → 貯金箱（将来の備え）
12. mile_suitcase  → 旅行のスーツケース（今しかできない経験）
13. mile_family    → 笑顔の家族4人（親2・子2・上半身）※小物は持たせない

【キャラ（太一さんのちびキャラ）】※本人写真を参照画像として渡して作る
14. taichi_smile   → にっこり笑顔の上半身
15. taichi_point   → 人差し指を立てて説明する上半身
16. taichi_worry   → 少し困った顔の上半身
17. taichi_wave    → 両手を振る上半身
```

## ■ 使い方（差し替え）
- 小物：`<Sticker icon="plane" …>` → `<Sticker img="mile_plane" …>`
- キャラ：`<Chara mood="point" …>` に `img="taichi_point"` を追加。
- 数字・矢印・ピル・スタンプ・下テロップ・方眼背景は図解側で出すので画像不要。
