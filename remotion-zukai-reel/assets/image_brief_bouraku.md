## 動きのイメージ
- **①**：地球儀がまわり、まわりに国旗がポンポンと次々に貼りつく → ビルが並ぶ → メダル。
- **②**：「でも、ここが落とし穴」でフタがパカッと外れて断面の穴が出る → 「中身は全部株式」で地球儀の中身が株の箱に変わる → 「株が下がるときは」で株の箱が次々に穴へ落ち、**地球儀も一緒にストンと落ちる**（土ぼこり＋嵐雲＋下がるグラフ）。
- **③**：3つのビン（株・債券・現金）。「増やそう増やそう」「とりあえず積立」に合わせて、コインが**毎月チャリンチャリンと株のビンにだけ**入っていく → 株のビンだけパンパン → シーソーが株側にガクッと傾く →「資産分散ができていない」。
- **④**：カレンダーの丸印（入学など）と暴落のグラフが重なる → 財布がしぼむ → 頭を抱える人。
- **⑤⑥**：株の箱の横に債券の巻物が並ぶ → 双眼鏡で「何年後にいくら」 → 南京錠でカチッ → 砂時計。
- **⑦**：あふれた貯金箱 → 太一ほっと → 旅行・家族の画像を次々に。
