# 児童手当リール 図解設計書 v2（作り直し・2026-11-22）

v1は「更新型・子どもNISAのノート＋カメラ下スクロール」のコピーで0点。v2はこれまでの引き出しを組み合わせて、この台本のためだけの形にする。

## 骨組み：ツリー式（1画面の地図が育っていく）
- 画面上に**ハブ「わが家の児童手当」**を常に置く。そこから**4本の枝**が線でつながる：
  **① どこに入れる？ ／ ② いくら？ ／ ③ なぜ運用？ ／ ④ 注意点**
- 最初は4本とも**グレーの「？」**（まだ開いていない枝＝続きが気になる）。話が来た枝だけ色がつき、下にその枝の中身が展開される。終わった枝は小さくたたまれて**答えの一言**だけ残る（例：「成長投資枠に一括」「約415万円」）。
- 最後にカメラが引いて、**4本の答えがそろった1枚の早見表**になる＝保存したくなる画面（ここが新しい山場）。
- 地の色は**薄いグレー＋細い方眼（設計図ふう）**。ノートの黄色はやめる。差し色＝緑（児童手当・運用）、青（銀行）、赤（物価・注意）。

## 字幕：ホップするハイライター（新）
- カラオケ式はやめる。1文を全部出して、**今しゃべっている言葉に角丸の色ボックスが飛び移る**（言葉は白抜き）。数字の所だけボックスが緑／赤になる。

## 枝ごとの中身（台本の秒数は録音どおり）
**ハブ登場（0〜2.7）**「わが家は、児童手当を全額NISAに入れています」
- 家族の絵 → ハブのカードがポン → 4本の線が一気に伸びて「？」が4つ並ぶ（0.03秒から動く・最初の1秒は音なし）。

**① どこに入れる？（2.7〜7.3）**「成長投資枠に一括投資／目的は大学資金の一部」
- 枝①が緑に。下に**型B フロー**：封筒（児童手当）→ 線 → NISAの箱（つみたて投資枠｜成長投資枠）。成長投資枠に**一括でドサッと**（ドサッの絵＋コインが一度に落ちる）。「一括」の上に**取り消し線リビール**：「毎月コツコツ？」→線が引かれる →「まとめて一括」。
- 「目的」：ドーナツがグッと埋まる（大学資金のうち一部＝児童手当の分だけ色がつく）。
- 枝①がたたまれて答え「成長投資枠に一括」が残る。

**② いくら？（7.3〜14.8）**「1人だいたい245万円／我が家の場合、上の子が18歳になるまでだと合計約415万円」
- 枝②が開く。**計算の図解（必須）**：
  - 1人：0〜18歳の帯。0〜3歳（オレンジ）「1.5万円×36か月＝54万」＋3〜18歳（緑）「1万円×191か月＝191万」→ 2つが合体して「245万円」がドン。
  - わが家：帯が2本に分かれる。上の子（今2歳→18歳）／下の子（今0歳→そのとき17歳）。2026年10月に赤い縦線、左のもらい済みは薄く消える。
    上の子 12万＋190万＝約202万／下の子 43.5万＋169万＝約212.5万 → 2本がハブに吸い込まれて「合計 約415万円」。
- 答え「約415万円」が枝に残る。

**③ なぜ運用？（14.8〜28.5）**「銀行に置いておくと約430万円・ほぼ横ばい／物価は2〜3%／インフレに負ける／年5%なら約650万円」
- **思い込みを先に見せて崩す**：吹き出し「銀行に置いておけば安心」→ 約430万円・「ほぼ横ばい」（眠るお金）。
- 「でも物価は」で**背景の幕が切り替わる**（薄グレー → 濃い赤茶の全面）：値札が上がる・2023年3.2%／2024年2.7%／2025年3.2%（消費者物価・総合）が1枚ずつ。お札が縮む →「インフレに負けてしまう」。
- 「もし年5%で」で幕が戻り、**ダッシュボード風のカード**（大きな数字が数え上がる＋面グラフが右上がり＋「▲」）→ 3本の棒で比較：もらう額415万（灰）／銀行430万（青）／年5% 約650万（緑）。お金の木。
- ※注記（読める大きさ）：年0.4%・年5%は計算のための仮定・元本保証なし。
- 答え「インフレに負けない」が枝に残る。

**④ 注意点（28.5〜41.8）**「わが家のケース／近いうちに使うなら運用はおすすめしません／2歳と0歳で長く持てる／株だけだとリスク／債券も持って備える」
- 枝④が開く。**2つに分かれる分かれ道（ツリーの小枝）**：
  - 「近いうちに使う」→ カレンダーであせる夫 → 短いグラフが下がったところで終わる → ✕「おすすめしません」
  - 「大学まで長い（2歳・0歳）」→ 時間の帯が長く伸びる → グラフが上下しながら右上がり → ◯「だから運用」
- 「株だけだと」：暴落であせる夫 → てんびんに「株」だけ乗って大きく傾く → 「債券」が乗って水平に戻る → 盾の家族「リスクにも備える」。
- 答え「長く持てるから・債券も」が枝に残る。

**全体像（41.8〜43.9 あたり）**：カメラが引いて、ハブ＋4本の答えがそろった早見表。

**締め（43.9〜51.3）**「スライドにまとめました／プロフのリンクから公式LINE／ここから受け取って」
- 早見表がそのまま**スライドの表紙に変わる**（地図→資料へ）。後ろでスライドが流れる。
- プロフの画面（リンクに赤丸）→ LINEのメニュー「特典はこちら」に赤丸。
