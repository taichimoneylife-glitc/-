## 1. 背景（なぜ今この話か）
- 2025年に証券口座の乗っ取り・不正売買が相次いだ。各社とも、パスキー（顔・指紋・端末のPINでログインする仕組み）などの認証強化を進めている。
- 楽天証券：2025年10月26日から全チャネルでパスキー認証を導入。2026年6月から、ログイン時のパスキーを順次必須化（利用者ごとに個別に案内）と報じられている。
- SBI証券：多要素認証（デバイス認証・FIDO・電話番号認証）を原則必須化。
- パスキーを入れても**古いパスワードでのログインが残る**と、そこが弱点になる。そのためSBI証券には、パスワードでのログインを無効にする設定がある。

## 2. SBI証券

### ✅ 公式で確認できたこと
| 対策 | 内容 | 注意点 |
|---|---|---|
| パスキー認証 | 顔・指紋・端末のPINでログイン | ログインパスワード無効設定の前提になる |
| ログインパスワード無効設定 | ユーザーネーム＋パスワードでのログインを無効にし、パスキーだけにする。対象はメインサイト（PC・スマホ）、スマホ専用サイト、SBI証券Plus | パスキーの設定が必須。**2026年7月10日以降**、有効にすると「アプリ・ツールのログイン制限」も自動でかかる。パスワードに戻すときは、そちらの解除も別に必要 |
| アプリ・ツールのログイン制限設定 | 普段使わないアプリ（米国株・先物オプション・FX・CFDなど）やPCツール（HYPER SBI 2など）からのログインを、1つずつ止められる | FIDOまたは電話番号認証の設定が必要 |
| 取引制限設定 | 商品ごとに取引を止められる（例：使わない外国株・FX・信用取引など）。公式FAQの「取引制限受付フォーム」から申し込む | 投信積立への影響、制限の範囲、解除方法は申し込み時に確認 |
| ログイン一時利用停止 | WEB・アプリ・ツールの**全部**でログインを止める | 停止中も積立の注文は原則出る。ただし「重要なお知らせ」を確認していないと注文が止まることがある。信用取引の人は追加保証金などに注意。法人口座は使えない。自分もログインできなくなる |
| ログイン履歴・ログイン通知メール | いつ・どこからログインされたかを見られる。ログインがあるとメールが届く | 早く気づくための対策 |
| 多要素認証の設定状況の確認 | パスキー／FIDO（スマホ認証）／電話番号認証の設定状況を確認できるページがある | — |
| 出金時の二要素認証 | 出金のときに認証が必要 | — |
| フィッシング注意 | 設定していても、偽サイトにログイン情報を入力しない（SBI証券も注意喚起） | — |

**整理：SBIの「ログイン制限」は別々の3つの機能**
| 設定 | 何ができなくなる？ | 積立・注意点 |
|---|---|---|
| ログインパスワード無効 | IDとパスワードでのログイン | パスキー必須。アプリ制限も自動でかかる |
| アプリ・ツールのログイン制限 | 指定したアプリ・PCツールからのログイン | 投信積立は設定どおり続く（例外あり） |
| ログイン一時利用停止 | WEB・スマホアプリ・PCの全ログイン | 投信積立は原則続く。重要なお知らせに注意 |

取引そのものの制限は、これとは別に「取引制限受付フォーム」で申し込む。

**画面の道順（個人の解説記事・図解ベース。実際の画面で要確認）**
- パスワード無効：パスキーでログイン → My設定 → 各種サービス → セキュリティ関連 → ログインパスワード無効設定 → 「有効」 → パスキーで認証
- アプリ制限：My設定 → 各種サービス → セキュリティ関連 → アプリ・ツールのログイン制限設定 → 「変更」 → アプリを選ぶ → 認証
- 取引口座の確認：My設定 → お取引関連・口座情報 → 取引口座
- 取引制限：公式FAQ「不正なアクセスを防止するための対策」 → 取引制限設定 → 取引制限受付フォーム
- ログイン一時停止：My設定 → 各種サービス → セキュリティ関連 → ログイン一時利用停止設定 → メールで本人認証

### ⚠️ 要確認（言い切らない）
- 「外国株を買ったことがなくても、外国株式の取引口座が開設されている場合がある」
- パスキー登録の細かい手順（「変更」 → 取引パスワード → メールの認証コード、など）
- ログイン一時停止の**解除の場所**（「各種制限設定」から／モバイルサイトから、など情報によって違う）
- ログイン通知の設定場所（公式では「ログイン履歴サービス」のページから利用する、という書き方）
- 「ログイン履歴は最大100件・過去2年以内」

## 3. 楽天証券

### ✅ 公式で確認できたこと
**公式セキュリティページの項目**
- ログイン時：パスキー認証（設定必要）、ログイン追加認証（設定必要）、楽天証券あんしんログイン（設定必要）、ログイン通知メール（設定不要）、ログイン履歴の確認（設定不要）
- 取引時：注文通知（設定必要）
- 不正出金防止：出金時の追加認証（設定不要）、出金先指定口座の変更停止（設定必要）、出金先を本人名義の口座に限定（設定不要）
- その他：取引やサービスの一時的な利用停止

**取引やサービスの一時的な利用停止（取引ロック）**
- ウェブで選べる5種類
  1. 投資信託の買付以外を停止
  2. 投資信託と出金以外を停止
  3. 外国株式のみ停止（米国株・中国株・アセアン株を含む）
  4. すべての取引を停止
  5. ログイン・すべての取引を停止
- 自動音声ダイヤルで選べる3種類：ログインを含むすべての取引の制限／投資信託の買付（積立含む）以外の制限／投資信託の売買（積立含む）と出金以外の制限
- ウェブでの設定手順：ログイン → マイメニュー → セキュリティ設定 → 再認証 → 「取引やサービスの一時的な利用停止」の「設定」 → 種類を選ぶ → 「認証へ進む」 → 登録電話番号に音声で届く6桁のワンタイムキーを入力
  - 再認証は、ID・パスワードでログインした場合はメールのワンタイムキー、パスキーでログインした場合はパスキー認証
- 自動音声ダイヤル：**0120-852-638**（無料・24時間・携帯からも可）。つながらない時は 03-6706-2753（有料）
  - 本人確認に必要なもの：部店・お客様コード、ログインID、生年月日（西暦8桁）、登録電話番号
- 解除
  - ウェブなら設定と同じ道順で「解除」 → ワンタイムキー
  - **ログインを含む制限の解除は自動音声ダイヤルで**行う。**登録した電話番号から**かける必要があり、ほかの番号や非通知では解除できない
  - 解除できるのは、自分で設定した利用停止だけ
- 停止中の注意
  - 投資信託の取引を止めると、積立注文はエラーになる（引落方法によっては代金が引き落とされ、あとで返金）
  - iDeCoの拠出は続く。外国為替取引は止まらない
  - 逆指値注文は、解除したときに想定外の価格で約定することがあるので、先に取り消す
  - 配当金・分配金・株主優待は受け取れる（出金停止中は出金できない）

**その他**
- 出金先指定口座の変更ロック：カスタマーサービスセンターに連絡すると、出金先口座の変更機能にロックをかけられる
- ログイン通知メール：2025年6月1日以降、自動で設定済み
- 注文通知：注文の受付・訂正・取消のときにメールが届く。自分で設定が必要で、商品ごとに設定する（2025年10月26日開始）
- 出金時の追加認証：SMSか音声のワンタイムキー。2025年10月26日以降は必須
- パスキー：2026年5月31日から、スマホがない人もパソコンにパスキーを保存できるようになった
- 日常の基本：メールやSMSのリンクからログインしない。AppleやGoogleなど、パスキーを保存している先のアカウントにも2段階認証をかける

### ⚠️ 要確認（言い切らない）
- 「パスキーを登録したら、原則パスワードでログインできない」
- 「出金先ロックの解除や出金先の変更は書面手続き」
- 5種類それぞれの「残せる機能／止まる機能」の表の中身（公式の表と1つずつ突き合わせる）
- 「ログイン通知は自分で解除できる」

## 4. 動画の構成案（オリジナルの切り口）
**切り口：口座を「家」にたとえる**（SBI証券編の例）
1. 鍵を強くする → パスキーにして、パスワードの鍵は捨てる（ログインパスワード無効）
2. 使わない勝手口を閉める → 使わないアプリ・ツールからのログインを止める
3. 金庫の使わない引き出しにロック → 使わない商品の取引制限
4. 留守の間は玄関ごと閉める → ログイン一時停止（積立は原則続く）
5. 防犯カメラを付ける → ログイン通知・ログイン履歴

楽天証券編は「5種類の取引ロック」が山場。積立だけの人は「投資信託の買付以外を停止」と1つに絞り、そのあと出金先ロックと緊急時の電話番号へ進む。

**流れの型**
- 冒頭：「この設定してないと乗っ取られるかも」＋設定の全体を見せる
- 1つずつ設定画面に寄り、押す所だけ明るくする
- 山場：「放っておくと…」で暗転し、「不正売買」「勝手に出金」などのハンコ
- 締め：チェックリストに順番にチェック → 「今すぐ確認」

## 5. 見せ方（参考リールの動きを分析した結果）
- **カメラ**：画面全体を1枚の大きな紙として、カメラが寄る・引く・横に流れる。動きは3〜8フレーム（約0.1〜0.25秒）で、最初ためて一気に動き、ピタッと止まる。動いている間だけ少しぶれる。
- **注目だけ明るく**：3〜4フレームで画面全体が暗くなり、見る所だけ黄色の太い枠で光る。説明が終わったら戻す。
- **引き出し線**：黄色い点 → 線がスッと伸びる → 説明の箱（白地・黒の太い枠・ぼかさないずらした影）。キーワードだけ色を変える。
- **出方**：1〜2フレームだけ「うすく少し大きく」出てから、くっきり正しい大きさで止まる。
- **場面の頭**：集中線 → 小さい「道順の札」（例：My設定→各種サービス） → 大きな見出し → 図。0.3秒でそろう。
- **キャラ**：画面の端に小さく常にいて、場面ごとに表情を差し替える。
- 実際の画面は、スクショを元に**描き直した簡単な画面**にする（個人情報が映らず、寄ってもくっきり）。
