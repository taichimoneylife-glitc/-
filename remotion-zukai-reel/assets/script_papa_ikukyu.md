# パパ育休で「手取り実質10割」になる取り方（確定版・2026-11-27 たいちさん「コレでいこうか」）

```
パパ育休を取る人
コレ知らないと
大損します
実は育休は、取り方しだいで手取り10割
逆に1日足りないだけで、数万円損することもあるので
損しない取り方を解説します

パパが手取り10割で育休を取るには
生まれてから8週間以内に
14日以上取ること
これが一番大事です

例えば、12月1日に生まれたとします
1日から28日まで休むと
この28日間は手取り実質10割
なんで10割かっていうと
14日以上取ると、給料の67%に13%が上乗せされて80%
これが「出生後休業支援給付金」っていう制度
しかも手当には税金も社会保険料もかからないので
手取りで見ると、実質10割
ちなみに29日目からは67%に戻って
実質、手取りの8割ちょっとになります

逆に、13日だと67%だけで、上乗せは0円
それと、育休中は社会保険料も免除なんですけど
ここがポイントで、免除は1か月分まるごと
月末を含むか、同じ月に14日以上休めばいいので
産後パパ育休を、14日ずつ別の月に2回取れば
2か月分が、まるごと免除になります

同じように、ボーナスの保険料にもルールがあって
ボーナス月に14日休んでも、ボーナスの分は免除されなくて
ボーナス月の月末を含めて、1か月を超えて休むと
ボーナスの保険料も免除になります

とはいえ、これは会社員の話で
個人事業主やフリーランスは、雇用保険がないので対象外
その代わり2026年10月から
国民年金の保険料が最大1年免除になりました

ちなみにママも育休を取るなら
パパが14日取らないと
ママも10割になりません

自分の場合はいくらもらえるのか？
何日取るといいのか？
気になる方は、プロフィールの公式LINEに
「育休相談」と送ってください
```

## 計算の前提（画面の小さい字・図解用）
- パパ33歳・月給33万円（賃金日額11,000円）・ボーナス12月52万円・協会けんぽ東京（2025年度 9.91%）・ママ月給25万円・12月1日生まれ（8週間＝1月26日まで）
- 80%＝1日8,800円／普段の手取り 約78%＝1日 約8,600円／67%は普段の手取りの約86%（8割ちょっと）
- 毎月の保険料（本人分）約4.8万円（標準報酬34万円×14.105%）／ボーナスの保険料 約7.4万円／13日だと上乗せ 約2万円（14日分）がなくなる
- 3つのルールは別：①上乗せ＝8週間以内に合計14日 ②毎月の保険料＝月末を含む or 同じ月に14日以上（働いた日は除く・その月まるごと）③ボーナスの保険料＝ボーナス月の月末を含めて1か月を超える
- 図解で補う：分けてOK／普通の育休でもOK／予定日とずれた時／額面の67%／上限（月給約50万円超）／180日以降50%／給料が出ると減ることも／年金は減らない／会社が申し出／2回はまとめて申し出（原則2週間前）／ボーナスは普通の育休で（ちょうど1か月はダメ）／国保は免除なし・ママは産前産後＋9か月・届け出が必要／雇用保険の条件／ママは16週間以内・専業主婦ならパパは自分の14日だけ／あとから振り込み／住民税は引かれる
- 図解の前に確かめる：公務員（育児休業支援手当金）／ボーナスが67%の計算に入らないこと
