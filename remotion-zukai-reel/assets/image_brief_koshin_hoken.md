# 更新型保険リール｜絵コンテと画像指示書（v1・24枚）2026-11-18

台本：assets/script_koshin_hoken.md（確定版）／事実：.claude/skills/zukai-reel/references/facts-koshin-hoken.md

## 考え方
- 主役は「同じ1人の男性が年をとっていく」流れ。保険料の階段と、年をとる本人の絵をそろえて見せると、自分ごとになる。
- 色：終身＝緑（ずっと続く）、定期・更新＝オレンジ（切れる・上がる）、危ない所＝赤。最後まで固定。
- 帯・年齢の線・保険料の階段・数字・「更新」の札・✕ は動画側で描く。画像は「人」と「実物の小物」だけ。
- 実在の保険会社名・商品名・ロゴは絵にも画面にも出さない。
- 動き：いつものノート＋カメラが線を追って下へ進む（flowKit）。

## 絵コンテ
**冒頭（トーク）**：たいちの口パク（taichi_talk_*）。1画面目の3行。

**① 正体と仕組み**
- 「その保険が」→ 封筒から保険証券が出てくる（kh_policy_envelope → kh_policy_doc）。証券に赤いハンコ「更新型」（動画側）。
- 設計書の形（左に保障の種類、右に帯）。終身の帯は緑の矢印で右へ抜ける／定期の帯は10年ごとに切れて「更新」の札。下に年齢の線 30→40→50。
- 「その年の年齢で保険料が決め直されます」→ 更新のお知らせのはがき（kh_renewal_notice）がポンと届く。
- 「年齢が上がるほど、病気や亡くなるリスクが高くなる」→ 同じ男性が 30代→50代→70代 と横に並ぶ（kh_man_30／kh_man_50／kh_man_70）、その上にリスクの矢印が右上がり。病院のアイコン（kh_hospital_worry）。

**② デメリット3つ**（見出し「デメリット3つ」＋ 1・2・3 の札が並ぶ）
- 1つ目：保険料の階段（1万→1.5万→2.7万→約6.2万）。各段に同じ男性の年齢違い（kh_man_30／kh_man_40／kh_man_50／kh_man_60）が立ち、段が上がるほど表情がくもる。
  - 「実は僕の父も」→ 60代の男性が保険料の通知を見て驚く（kh_father_shock）。「父：月8万円超え」の札がドンと落ちる。財布が軽くなる（kh_wallet_empty）。
- 2つ目：「保険料を安く更新しようとすると」→ ハサミで保障の紙を小さく切る（kh_scissors_cut）→ 盾が小さくなる（kh_shield_small）。「いざという時に」→ 入院中のベッドで請求書を見て困る（kh_hospital_bill）。
- 3つ目：設計書の帯が上から1本ずつ足される（死亡・三大疾病・入院・介護）。右端に「80歳まで」「70歳まで」の札、そこで帯がプツッと切れる。切れた先に高齢の夫婦（kh_elderly_couple_80）が、消えていく傘の下で困る（kh_umbrella_gone）。

**③ 僕の考え**
- 「これが、更新型保険の全体像」→ カメラが引いて ① の設計書に戻る。切れた帯に赤い✕。
- 「今は長生きの時代」→ 90歳くらいの元気な夫婦が誕生日ケーキで笑顔（kh_long_life）。
- 「必要な保障を把握した上で」→ 夫婦が保障のリストをチェックしている（kh_couple_checklist）。
- 「一生涯続く終身タイプで」→ 終身の緑の矢印が最後まで続き、家族が大きな傘の下で安心（kh_umbrella_family）。
- 「数年に一度見直して、アップデート」→ 終身の矢印の上に「見直し」の丸が数か所。FPと夫婦が証券を見ながら相談（kh_review_meeting）。

**締め（トーク）**：たいちの口パク。「まずは更新型保険なのか確認」→ 家で保険証券を広げて確認する夫婦（kh_couple_check_policy）を小さく。「保険料が安くなった人」→ 喜ぶ夫婦（kh_couple_happy）。「ぜひご相談ください」→ いつものTapCard（プロフ → 相談）。

## 作ってほしい画像（24枚）
```
【共通スタイル】※毎回この文と、太一の画像（基準）を添付する
添付画像のキャラクターと同じ絵柄で描いてください。
茶色の細い輪郭線、やわらかいパステル調の塗り、軽い陰影、ほんのり紙の質感。
線の太さ・色の明るさ・塗り方は添付画像とそろえる。
透過PNG（背景なし）、正方形、被写体は中央で余白多め。
文字・数字・ロゴ・企業名は入れない。
1枚ずつ別の画像として出す（1枚に複数を並べない）。
「同じ男性」は、同じ顔立ち・髪型・服の色（オレンジ系のシャツ）で年齢だけ変える。

【同じ男性が年をとる】
1.  kh_man_30            → 30歳くらいの男性、全身、にこやかに立っている
2.  kh_man_40            → 同じ男性が40歳くらい、全身、少し疲れた表情
3.  kh_man_50            → 同じ男性が50歳くらい（白髪まじり）、全身、困った表情
4.  kh_man_60            → 同じ男性が60歳くらい（白髪）、全身、不安そうな表情
5.  kh_man_70            → 同じ男性が70歳くらい（白髪・少し腰が曲がる）、全身、心配そうな表情

【人・場面】
6.  kh_father_shock      → 60代の男性が、手に持った通知の紙を見て目を丸くして驚いている、上半身
7.  kh_hospital_worry    → 病院の建物の前で、中年の男性が胸に手を当てて不安そうにしている、全身
8.  kh_hospital_bill     → 病院のベッドに座った中年の男性が、請求書の紙を見て困っている、上半身
9.  kh_elderly_couple_80 → 80歳くらいの夫婦が並んで立ち、困った顔で顔を見合わせている、全身
10. kh_long_life         → 90歳くらいの元気な夫婦が、誕生日ケーキを前に笑顔、上半身
11. kh_couple_checklist  → 30代の夫婦が、1枚のチェックリストの紙にペンで印を付けている、上半身
12. kh_umbrella_family   → 大きな緑の傘の下で、夫婦と子ども2人が安心した笑顔、全身
13. kh_review_meeting    → スーツの若い男性（相談役）が、夫婦に机の上の書類を見せて説明している、上半身、おだやか
14. kh_couple_check_policy → 家のテーブルで、夫婦が保険の書類を広げて見ている、上半身
15. kh_couple_happy      → 夫婦が書類を手に、ほっとした笑顔でハイタッチ、上半身

【小物】
16. kh_policy_envelope   → 大きめの白い封筒（中から書類が少し見えている）
17. kh_policy_doc        → 保険証券の書類1枚（表のような線だけ。文字・数字なし）
18. kh_renewal_notice    → はがき1枚（オレンジの帯が入ったお知らせ。文字なし）
19. kh_wallet_empty      → 口が開いた財布から、最後のコインが落ちていく
20. kh_scissors_cut      → ハサミが書類を小さく切り取っている
21. kh_shield_small      → 小さくなってヒビが入った盾
22. kh_shield_big        → 大きくてしっかりした緑の盾（kh_shield_small と対で使う）
23. kh_umbrella_gone     → 高齢の夫婦の頭の上の傘が、上から消えかけている（傘が半透明）、全身
24. kh_hourglass         → 砂時計（砂が残り少ない。「決まった年齢で終わる」に使う）
```

## 今あるものを使う
- たいち：冒頭・締めは taichi_talk_*（口パク）。③の「個人的には」で taichi_one_finger／taichi_think_chin。
- 病院のアイコン：ic_hospital があれば kh_hospital_worry の代わりにしてもよい。
- 年数のカレンダー：ic_calendar_years を「10年ごとに」に使う。
