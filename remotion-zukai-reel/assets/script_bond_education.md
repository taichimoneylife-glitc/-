# 教育資金×債券 台本（確定版 v3・③の数え方を直した版 2026-11-24・たいちさん「コレで確定かな」）

## 冒頭の画面の文字
もしも教育資金を使う時に
暴落したらどうなるのか？

## しゃべる言葉
実は最近、米国株は最高値から10%を超える下落がありました
もし教育資金を使う時に暴落が来たら
どうなるのか
過去の暴落をもとに解説します

例えば、教育資金を株で500万円用意して
残りは現金だけ、という家庭
リーマンショックのとき
米国株は1年で約37%下がり
500万円が約317万円になりました
入学金や授業料は待ってくれないので
下がったところで売るしかないこともあります

でも、ここが落とし穴
株は大きく下がると
元に戻るまで何年もかかることがあります
リーマンショックでは約5年半
ITバブルでは約7年
過去の大きな暴落7回のうち4回は
3年たっても戻っていません

例えば、子どもが中学3年の冬に暴落が始まったとします
大学入学までは、あと3年
暴落の前に500万円あった株は
3年たっても、約460万円までしか戻っていません
つまり、危ないのは使う年の暴落だけではなくて
暴落したあと
戻るまでにどれくらいかかるかわからないことです

だから僕は、株と一緒に債券も持っています
NISAの一部を売って債券に移し、今は500万円
株が下がっている間は債券を使い、株が戻るまで待つ
株が上がっていれば、株から使う
その時の状況に合わせて、柔軟に対応しやすくなります

景気悪化で株が下がるときは
歴史的に見ると債券が上がる傾向にあります
暴落のときは、景気を支えるために金利が下がりやすく
金利が下がると、債券の価値が上がるからです
実際、リーマンショックの年は
株が約37%下がった一方で
アメリカの10年国債は約20%上がりました

米国株が下がった年の、約8割で債券はプラス
ただ2022年のように
株も債券も一緒に下がった年もあります
そして今、アメリカの10年国債の金利は5%前後
増やしやすく、暴落の備えにもなりやすいので
債券も選択肢に入れやすいと思います
つまり、どれか1つだけではなく
何が起きても対応できる資産分散が
個人的には一番大事だと思っています

教育資金は
使う年に暴落することだけがリスクではありません
使う数年前に暴落して
使う年までに戻らないケースもあります
まずは今の資産が、何か1つに偏っていないか
確認してみてください

## 数字の根拠
- 冒頭：「最高値から10%を超える下落がありました」（過去形・2026-11-25 たいちさん決定）。根拠：S&P500 10/6 最高値7,818.93 → 11/20 終値6,910.39（約−11.6%）。11/23 +4.7%で7,237、11/24 7,201（約−7.9%）。過去形なので録る日に戻っていても事実のまま
- リーマンショック：S&P500 配当込み 2008年 −36.55% → 500万→約317万。直前（2007年末）500万 → 2008末317 → 2009末400 → 2010末459（3年後もまだ下）
- 回復：リーマン約5年半（2007/10→2013/3）、ITバブル約7年、7回のうち4回が3年で戻らず（世界恐慌・オイルショック・ITバブル・リーマン）
- 2008年 米10年国債 +20.10%／2022年 S&P −18.04%・米10年債 −17.83%
- 98年で26回・21回（Damodaran 1928〜2025）✓ 2026-11-24 元データ（pages.stern.nyu.edu histretSP）で数え直し確認。株マイナス26年・うち米10年国債プラス21年（約81%＝約8割）。債券もマイナスの5年：1931・1941・1969・2018・2022。2000年 株−9.03%/債+16.66%、2002年 −21.97%/+15.12%、2008年 −36.55%/+20.10%、1974年 −25.90%/+1.99%、2022年 −18.04%/−17.83%
- 米10年債利回り 5%前後（2026年11月）
- ③：2007年末（中3の冬・暴落の前）500万 → 2010年末（3年後・高3の冬）約459万＝約460万円。317万の所から数えると3年後は約468万・2012年春には500万超えなので、数え始めは「暴落の前」にする（2026-11-25）
