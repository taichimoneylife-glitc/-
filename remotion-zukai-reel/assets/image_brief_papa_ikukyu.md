# パパ育休 画像指示書 v2（2026-11-27 見直し）

台本：assets/script_papa_ikukyu.md。冒頭は実写なので画像なし。カレンダー・棒グラフ・ハンコ・数字・封筒の厚さは動画側で描く。画像は「人の気持ち」と、台本の言葉に直結する小物だけ。

## v1からの見直し
- 気持ちが変わる所は「同じ構図で表情だけ違う2枚」（ペア）にする。動画でその場で差し替えると、人物が反応して見える（教育資金×債券の「余裕→青ざめる」が効いた形）。
- 台本で言わない抽象的な小物（同じ厚さの封筒・少ない財布）はやめる。動画で描くか小さい字で足りる。
- 「パパが仕事の都合で取らない」を絵で見せる（会社で働く夫）。
- 人物はカレンダーの横に立つので、向きを指定する。

## 共通スタイル（毎回この文と、太一の画像（基準）を添付）
```
添付画像のキャラクターと同じ絵柄で描いてください。
茶色の細い輪郭線、やわらかいパステル調の塗り、軽い陰影、ほんのり紙の質感。
透過PNG（背景なし）、正方形、被写体は中央で余白多め。
文字・数字・ロゴ・企業名は入れない。1枚ずつ別の画像として出す。
夫は20代後半、紺のニット。妻はベージュのカーディガン。
赤ちゃんは pk_family_happy_baby と同じ顔・同じクリーム色の葉っぱ柄のおくるみで、どの画像でも同じ子に見えるように。
「ペア」の2枚は、同じ構図・同じ服・同じ大きさ・同じ位置で、表情と手だけを変えてください。
```

## 作ってほしい画像（14枚）
```
1.  pk_family_newborn      → 夫婦が生まれたばかりの赤ちゃんをのぞき込んで笑顔（病院のベッドの横）、上半身
2.  pk_dad_hold_baby       → 夫が家で赤ちゃんを抱っこして、やさしい笑顔、上半身、体は少し右向き

【ペアA：14日と13日】
3.  pk_dad_calendar_ok     → 夫が右を向いて、右手の人差し指で何かを指さしながら笑顔（カレンダーの日にちを数えている）、上半身
4.  pk_dad_calendar_oops   → 3と同じ構図で、指したまま「しまった」と青ざめる（汗）

【ペアB：ボーナス】
5.  pk_dad_bonus_happy     → 夫がボーナスの袋（のし袋のような封筒・文字なし）を両手で持ってうれしそう、上半身
6.  pk_dad_bonus_sad       → 5と同じ構図で、袋を見て残念そうな顔

7.  pk_dad_submit          → 夫が会社で上司に書類を両手で渡している（育休の申し出）、上半身

【ペアC：フリーランス】
8.  pk_freelance_worry     → 自宅の机でノートパソコンの前に座る父（紺のニット）が、困った顔で頭をかく、上半身
9.  pk_freelance_relief    → 8と同じ構図で、ほっとした笑顔

10. pk_dad_at_work         → 夫が会社の机で忙しそうにパソコンに向かっている（育休を取らずに働いている）、上半身

【ペアD：ママ】
11. pk_mom_baby_smile      → 妻が赤ちゃんを抱っこして、やさしい笑顔、上半身、体は少し左向き
12. pk_mom_baby_worry      → 11と同じ構図で、困った顔

13. pk_family_happy_baby   → 夫婦が赤ちゃんを真ん中に3人で寄りそって笑顔（家族の時間）、上半身
14. pk_dad_phone_line      → 夫がスマホでメッセージを送っている、明るい顔、上半身
```

## 使う場所（台本の言葉）
| 台本 | 画像 |
|---|---|
| 生まれてから8週間以内／12月1日に生まれたとします | 1 |
| この28日間は手取り実質10割 | 2 |
| 14日以上取ること → 13日だと上乗せは0円 | 3 → 4（その場で差し替え） |
| 14日ずつ別の月に2回（まとめて申し出・図の札） | 7 |
| ボーナスの保険料にもルール → 14日だと免除されない → 1か月を超えると免除 | 5 → 6 → 5 |
| 個人事業主やフリーランスは対象外 → その代わり国民年金が免除 | 8 → 9 |
| パパが14日取らないと（仕事で取らない） | 10 |
| ママも10割になりません | 11 → 12 |
| いくらもらえるのか／何日取るといいのか | 13 |
| 公式LINEに「育休相談」と送ってください | 14 |
