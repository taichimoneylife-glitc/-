# パパ育休 画像指示書（2026-11-27）

台本：assets/script_papa_ikukyu.md。カレンダー・棒グラフ・ハンコ・数字は動画側で描く。画像は人と小物だけ。

## 共通スタイル（毎回この文と、太一の画像（基準）を添付）
```
添付画像のキャラクターと同じ絵柄で描いてください。
茶色の細い輪郭線、やわらかいパステル調の塗り、軽い陰影、ほんのり紙の質感。
透過PNG（背景なし）、正方形、被写体は中央で余白多め。
文字・数字・ロゴ・企業名は入れない。1枚ずつ別の画像として出す。
夫は紺のニット、妻はベージュのカーディガン。
赤ちゃんは同じ顔・同じ白いおくるみで、どの画像でも同じ子に見えるように。
```

## 作ってほしい画像（12枚）
```
1.  pk_family_newborn     → 夫婦が生まれたばかりの赤ちゃんをのぞき込んで笑顔（病院のベッドの横）、上半身
2.  pk_dad_hold_baby      → 夫が家で赤ちゃんを抱っこして、やさしい笑顔、上半身
3.  pk_dad_calendar       → 夫が壁のカレンダー（数字なし・白いマス）を指でなぞって日にちを考えている、上半身
4.  pk_dad_oops           → 夫が書類を見て「しまった」と青ざめる（1日足りなかった）、上半身
5.  pk_envelope_same      → 同じ厚さの封筒が2つ並んでいる（給料と手当が同じくらいのイメージ）
6.  pk_dad_submit         → 夫が会社で上司に書類を両手で渡している（育休の申し出）、上半身
7.  pk_bonus_bag          → ボーナスの袋（のし袋のような封筒・文字なし）が少し光っている
8.  pk_freelance_dad      → 自宅の机でノートパソコンを使って仕事をする父（個人事業主・紺のニット）、上半身
9.  pk_mom_baby_worry     → 妻が赤ちゃんを抱っこしながら、困った顔で書類を見ている、上半身
10. pk_dad_wallet_empty   → 夫が中身の少ない財布を見て少し困っている（手当はあとから振り込み）、上半身
11. pk_family_happy_baby  → 夫婦が赤ちゃんを真ん中に3人で寄りそって笑顔（家族の時間）、上半身
12. pk_dad_phone_line     → 夫がスマホでメッセージを送っている、明るい顔、上半身
```
