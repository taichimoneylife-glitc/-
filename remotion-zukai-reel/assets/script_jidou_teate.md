# 児童手当 台本（確定版 2026-11-22・たいちさん「これで確定」）

## 本文（読む言葉）
2歳と0歳の子どもがいるわが家が
児童手当を
どうしているのか解説します

わが家は、児童手当を全額NISAに入れてます
具体的には成長投資枠に一括投資
目的は、子どもの大学資金の一部

児童手当は1人だいたい245万円もらえて
我が家の場合
上の子が18歳になるまでだと、合計約415万円
これを銀行に置いておくと、約430万円
ほぼ横ばい
でも物価は、ここ数年2〜3%台で上がっているので
インフレに負けてしまう
もし上の子が18歳になるまで
年5%で運用できたら約650万円

これはあくまで、わが家のケース
もし教育資金を、近いうちに使う予定があるなら
運用はおすすめしません
うちは2歳と0歳で、大学まで長く持てるから運用していて
株だけだとほんとにリスクが高いので
債券も持ってリスクにも備えています

0歳と2歳の子どもがいる僕が
実際にしている教育資金の貯め方を
スライドにまとめました
欲しい方は、プロフのリンクから公式LINEを追加して
ここから受け取ってください

## 数字の根拠（図解に必ず入れる）
- 1人245万：1.5万×36か月＝54万＋1万×191か月＝191万（4月生まれ・0歳から全部）
- 上の子（2024/5生・18歳まで）：1.5万×8＝12万＋1万×190＝190万 → 約202万
- 下の子（2026/2生・そのとき17歳）：1.5万×29＝43.5万＋1万×169＝169万 → 約212.5万
- 合計 約414.5万 → 約415万（2026年10月分から2043年3月まで）
- 銀行 年0.4%：約429万 → 約430万／年5%：約653万 → 約650万（毎月入れる・月利＝年利÷12）
- 物価（消費者物価・総合）：2023年 3.2%、2024年 2.7%、2025年 3.2%
