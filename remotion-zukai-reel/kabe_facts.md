# 年収の壁(2026)｜確定ファクト（出典つき・整理）

> 出典：太一さん提供のリサーチdoc「年収の壁リール｜情報整理」(2026-10-06)＋国税庁・厚労省。投稿では推定を断定しない。

## 数字（2026年分が主役）
| 壁 | 数字 | 注記 |
|---|---|---|
| 所得税 | 103万→160万(2025)→**178万(2026)** | 「去年160万→今年178万」が安全な並べ方。恒久＋時限の合わせ技（2028年分は168万＝推定） |
| 住民税(所得割) | **110万**（2027年度〜119万） | 一番先にかかる。均等割の非課税は自治体差（例:福井96.5万） |

| 社保・130万 | **変わらず**（19〜22歳は150万） | 家族の扶養を外れ、勤め先社保 or 国保・国民年金へ |
| 扶養(配偶者控除)満額 | **136万**（夫の年収約1,095万以下が前提） | 123万は去年 |
| 配偶者特別控除 満額 | **169万** | 超〜207万で段階減→207万超でゼロ |

## 働き損（すべて推定・前提明記）
- 前提：40歳未満（介護保険料なし）、健保約5%＋厚年9.15%＝約14%、税金は考慮せず。
- **130万超で国保＋国民年金を自分で払う**（50人以下の会社など）＝国民年金だけで年約21.5万＋国保 → **手取りが戻るのは約160万前後**。← 一番損が大きい。
- 51人以上で勤め先社保（106万ライン）＝本人負担約15万、回復123〜125万（損は小さい）。
- 結論：**「本当に怖いのは130万（国保落ち）」**。

## 保険屋の切り口（差別化）
- 勤め先社保に入ると：傷病手当金（給料の約2/3）・出産手当金・障害厚生年金・遺族厚生年金がつく。
- **国保にはこれらが基本なし** → 同じ130万を超えるなら、勤め先の社保に入れる働き方が得。
- 扶養内のままの配偶者＝傷病手当金なし → 保険で備えるきっかけ。共働きで配偶者の生命保険料控除も使える。
- 「壁で縮こまる」より「世帯の手取りと保障」で考える＝個別相談の入口。
