## 動き（数字）
- **ページ替えはゼロ**。1枚の長い地図をカメラが下へスクロールするだけ。
- 下へのスクロール（線を追う）：1フレームの移動 -6→-12→-18→-24→-36→-48→**-66〜-90（山）**→-72→-48→-36→-24→-12→-6 で、**約15フレーム（0.5秒）のなめらかな山形**（ゆっくり出てゆっくり止まる）。1回で約600〜700px（1080x1920換算）。15.8・21.3・29.7・31.5・35.7・46.3・58.9・62.9・65.3・66.9・67.7・72.3・76.0秒など、**ほぼ2〜5秒ごと**。
- 右下へ（線が横へ曲がる所）：13.3秒 +30〜+84,-30〜-102（斜め）。45.3秒 +54,-132（斜め）。
- **戻ってまた戻る（回想）**：32.2秒 下向き +150→+276→**+396**→+228→+102（約10f）で上の入力欄まで戻る→約1秒止まる→33.4秒 -90→-156→-330→**-408**→-228→-108（約10f）で元の位置へ。**ふだんのスクロールの約5倍の速さ**。

### フロー図の部品の出方
- 文字：**1文字ずつ打たれる**（約2コマに1文字）。例：「Claudeで動画が」f190〜199、「誰でも同じ動画を」f336〜345、「データベースを構築」f1257〜1280、「僕のフォルダはこういう構造」f1399〜1430。
- 大見出し（コスパ最強・フォルダ構築・プロンプト地獄など）：**横からブレながらすべり込む**（約5f）か、**下からぼけて上がりながらくっきり**（約5f）。出たあと、光のにじみが残る。
- 札（安い・早い・上手い／ルール・ナレッジ…）：1つずつ。出る瞬間に**ぼけ＋全体が少し横に揺れる**（f533〜536・f552〜556）。分かれ道の線は、縦の線→横の枝の順に伸びてから札が出る（f1235〜1256）。
- 枠で囲む：4つの札がそろうと、まわりに四角い枠が描かれる（f1312〜1320・f2384〜2390）。
- 画面カード（入力画面・フォルダの木・グラフの箱）：**下から少し傾いた状態で上がってきて、まっすぐになる**（立体の傾き→平ら、約9f。f1389〜1399・f2171〜2180）。

- 次の言葉の予告：カメラが動く**前に**、画面の下に次の言葉が小さく先に出る（「Claudeに」f640・「これだけで」f893・「ほんとなくて」f1198）。

- **吸い込まれる**：長いプロンプトのカードが、小さくなりながらフォルダのアイコンの中へ落ちる（f1890〜1902）＝「フォルダで勝手に毎回読み込まれる」を絵で見せる。そのあとカーソルがフォルダをクリック（f1925〜1940）。

## 台本の型
1. 冒頭（0〜13秒）：**「今から作る」実演の宣言**＋「見ても分からないかもしれないけど全部見せる」＋「このままやれば誰でも作れる」
2. 手順①（13〜29秒）：まず〇〇を使って → なぜか（安い・早い・上手い＝コスパ最強）→ こう伝える（実際の入力を打って見せる）
3. 問い（29〜37秒）：「これだけで完成。なんでこんな適当な指示で？」→ **答えの一言**（フォルダ構築）
4. 常識崩し（38〜45秒）：「神スキル何選みたいなのは本当なくて」→ 本当の要＝データベース＝センターピン
5. 具体（46〜59秒）：僕のフォルダの中身を実物で見せる（木→CLAUDE.md→1行ずつ）
6. 比べる（59〜67秒）：みんな＝長いプロンプトを毎回書く／僕＝フォルダで毎回読み込ませる＝仕組み化
7. 痛点（67〜76秒）：しないと → プロンプト地獄 → AI使ってる気になるだけ → 成果につながらない（下がるグラフ）
8. 結論（76〜81秒）：だから一番大事なのはフォルダ（作業場の構築）。**CTAなしで言い切って終わる**

## まねできること（太一のリールに使う時）
- **1本の線でつなぐ長いフロー図＋カメラが線を追って下へ**：ユーザーが一番好きな「線でつなぐ連結図解」（connected-diagram.md）の上位版。ページ替えなしで話が1本につながって見える。0.5秒の山形スクロールを2〜5秒ごと。
- **回想の往復**：「さっきの〇〇で」と言った時、カメラが一瞬で上の項目へ戻って光る枠→また戻る。説明を繰り返さずに思い出させられる。
- **クリックして横へ入る**：項目をカーソルでクリック→横へシュッ→中身のカード。「中身を見せる」場面に。
- **入力欄に1文字ずつ打つ**：実際の操作を見せると「このままやればできる」が伝わる（こどもNISAなら証券アプリの画面のイメージなど）。
- 分かれ道の札（1つから3〜4本）→最後にまた同じ札が戻ってきて結論を囲む（41秒と76秒）＝伏線の回収。
- 見た目（赤背景・明朝のグロー）はそのまま持ってこない。太一のノートの見た目のままで、**線を追うカメラ・回想・クリック・打ち込み**の動きだけ使う。
