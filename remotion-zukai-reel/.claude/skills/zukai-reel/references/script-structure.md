# リール構成の型（台本プレイブック）

毎回ゼロから悩まないための"型"。情報を並べるのではなく、視聴者が動く1本の物語にする。
新しい台本を書くときは、まずこの型に素材を流し込んでから調整する。

## 基本思想（3つ）
1. **並べない＝物語にする**。「え、そうなの？」→「自分やばいかも」→「じゃあどうすれば？」と感情が動く流れを作る。
2. **主役はナレーション**。話し手の口調・言い回し・区切り（「〜なんですよね」「例えば」「見落としがちなのが」等）に寄せる。図解は補強。
3. **数字・事実は必ず出典で裏取り**（憶測禁止）。医療・お金は特に厳密に。

## 王道の型（解説リール・7〜8ビート）
1. **フック（〜3秒）**：常識のズレ or 問い。「〇〇って、なんとなくで△△してませんか？」
2. **情報提供（プロとして現状）**：客観データで"今どうなってるか"。ここで信頼を得る（羅列でなく2〜3点に絞る）。
3. **誤解を崩す（"え、そうなの？"）**：みんなが安心している前提を1つ崩す（例：高額療養費あるから大丈夫→実は対象外だらけ）。
4. **自分ごと化（想像させる）**：「ちょっと想像してみてください」で読者の生活（教育費・老後・家族・仕事）に接続し、損失を体感させる。
5. **本題の痛点（損失回避）**：一番見落とされている痛点を突く（例：治療費より"収入減"）。各データに"放置の損"を一言添える。
6. **数字の一撃**：記憶に残る短い一文（例：「治療費と収入減で、数百万円が飛んでいく病気」）。
7. **CTA／引き**：単発＝個別相談へ（プロフ/DM）。シリーズ＝「次回〇〇を解説します」で引く。

## シリーズもの
- 2本目以降は「前回〇〇を話しました」で受け、冒頭で軽くおさらい → 本編 → CTA。
- 1本目の締めは、2本目の"必然性"になる引きで終える（例：長期化・通院・収入減 → だから昔の保険じゃ守れない → 次回選び方）。

## 図解（プロ級を狙う）
- **1ページ＝1メッセージ＋1ビジュアル**。データはカード／バー／比較／チェブロンで。
- **ハブ型レイアウト**（中央にテーマ＋周りに要素＋キャラ吹き出し＋データカード）は解説と相性抜群。参考：保険会社パンフ級の図解。
- **常時ズーム／ケンバーンズ**（表示中ずっと微拡大）、**スプリング登場**、キーワードに**手描きマル**、強調時に**プッシュイン**（参考：Opus5.5リール）。
- 全ページ**画面いっぱい**（セーフエリア充填、UI被り回避）。色=薄黄#FBF6D8×緑・Noto Sans JP。

## 効果音
- **出現ごと**に控えめに、種類は多彩。車リールと同等の存在感（ナレーション音量差を補正して調整）。

## 文字数の目安（実測より・`script-analysis-gan1.md`）
- 目標尺を先に決める：**60〜90秒＝550〜650字** / 100〜110秒＝750字前後。
- **フック 40〜50字**（短く刺す）。**1図解 60〜110字**が標準、**山場だけ140字前後**に厚く。
- **転換ページは短く（60字前後）**＝「一方で」「ただしここからが重要」で切替。
- 各図解に文字数を割ってから書く。山場は1つに絞る。数字は口語で丸め、正確値は出典メモへ。

## チェック（台本を出す前に自問）
- 情報を並べただけになっていないか？（"え/自分ごと/だからどうする"があるか）
- 話し手の口調になっているか？
- 数字はすべて出典があるか？
- 1ページ＝1メッセージで図解に落とせるか？
- 締めは行動（相談/次回）につながっているか？
