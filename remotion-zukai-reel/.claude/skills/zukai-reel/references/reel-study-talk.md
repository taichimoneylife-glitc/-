# 参考リール研究：トークリール（実写トークヘッド＋オーバーレイ図解／43秒）

顔出しトーク動画に、**語ごとテロップ・効果音・図解パネル・寄りズーム**を大量に重ねる編集。
「Opus5.5が全部自動編集してくれる」という内容のメタ動画。**この編集そのものを自動化する**のが目標。
※私たちの図解キット（薄黄フラット全画面）とは別モードだが、**図解の語彙は流用できる**。違いは「背景が実写トーク映像」であること。

## 出典動画の"編集仕様"（ラストのEDIT LOGパネルより＝この人が明言している内訳）
20分のYouTube1本に対して:
- **テロップ 248枚**（＝ほぼ全発話に字幕。語ごとに強調）
- **効果音 686個**（＝出現・転換・強調ごとに1つ。とにかく多い）
- **図解アニメ 100場面**（＝アイコン/フロー/進捗バー/カレンダー等のパネル）
- **画面収録 20本**（＝実際のPC操作/アプリのスクショ・録画）
- **BGM 6曲**（＝区切りで曲調チェンジ）
- **寄り（ズーム） 229回**（＝ほぼ毎ビート、話者にプッシュイン）

→ 密度の思想：**1発話ごとに「テロップ＋SFX＋（必要なら）図解＋寄り」を必ず当てる**。静止した素の顔映像が続く瞬間を作らない。

## レイヤー構成（下から）
1. **実写トーク映像**（縦9:16・話者センター・宅studioの引き）。ときどき grid/方眼紙背景や別Bロールに差し替え。
2. **寄りズーム（Ken-Burns/パンチイン）**：話者に対して scale 1.0→1.08 を短時間、大事な語で寄る。これが229回＝体感ずっと動いてる主因。
3. **図解パネル（上1/3）**：頭の上のスペースに乗せる。ポップ登場（スプリング）＋SFX。
4. **テロップ（下1/3）**：語ごとに出す。
5. **アクセント**：手描き下線・星・マル、点線コネクタ、「完成」赤スタンプ、キラッ(sparkle)転換VFX。
6. **BGM**：軽いベッド。

## テロップの型（最重要・248枚の作り）
- 位置：画面下1/3。大きい**丸ゴシック極太**、白ベース＋黒縁/影で実写上でも読める。
- **語ごと（カラオケ式）**に、発話に同期して出す（1〜4語ずつ）。
- **強調カラー**：
  - オレンジ＝キーの名詞（例「Opus 5.5」「Claude」「企業」）
  - 緑＝ポジ/結果（例「出来上がってる」「絶対」「完成」）
  - 青＝概念（例「ワークフロー」）
  - **黄マーカー蛍光ボックス**＝一番刺す語（例「全部編集」「自動」「毎日」）
- 上にうっすら**小さいグレーの前振り字幕**（例「撮ったら あとは」）を置くことも。

## 図解パネルの語彙（100場面＝私たちのキットでほぼ再現可能）
出典に出てきた実物:
- **番号アイコンステップ**：`01 撮影` の角丸ダークカード＋アイコン。
- **フロー矢印**：`撮影 → Claude → 自動編集(After Effects)` を横に、緑チェックで完了。
- **進捗バー＋ノード**：`Claude が編集中.. 8%→45%→83%→100%完成!`（色が緑に育つ）。下に手順アイコンが順次増える（撮影→ご飯→ジム→完成サムネ✓）。
- **before/afterカレンダー**：`月火水木金土日` に「編集」タグ＋ストップウォッチ「1時間」（赤）。
- **WORKFLOWレール**：`撮影 → Claude自動で編集(強調) → 投稿`、右上に「これから」タグ。
- **ノード・ファンアウト図**：丸く切り抜いた本人アイコン → 点線で複数の企業ビルアイコンへ（「AI編集ができる→企業にどんどん営業」）。
- **擬似UIカード**：YouTubeサムネ風カード（アイコン＋「月20万円↑ 作り方を公開」＋20:25）、**コメント欄UUIモック**（「AI」と入力＝CTA誘導）。
- **チェックリスト集計パネル**（EDIT LOG）：項目＋大きい数字＋緑✓が1行ずつ出る。裏に編集タイムラインUI（テロップ/効果音/BGMトラックが色分け）。
- **タイマー/ストップウォッチ**の黄アイコン、**完成の赤マルスタンプ**、**「この間に」注釈矢印**。
- 傾けた**スクショカード**を数枚並べる（最近の投稿）。

## 効果音（686個＝出現ごと必須）
- pop＝テロップ/パネル出現、whoosh/swipe＝スライド・転換、tick/count＝%カウント、ding/correct＝チェック・強調、sparkle＝キラッ転換、finish＝完成。
- 私たちの音源（up1-10, pop, swipe, count, correct, finish）で代替可。**発話ごとに最低1つ**当てる密度で。

## 自動化の設計（私たちのパイプラインへの落とし込み）
入力＝ユーザーの喋り動画1本 → 出力＝上記編集済みリール。
1. **文字起こし（語タイムスタンプ）**：faster-whisper で word-level タイムスタンプ → テロップ割り（1〜4語/枚）と強調語の抽出。
2. **Remotionで実写を下敷き**：`<OffthreadVideo src={staticFile("talk.mp4")} />` の上に、
   - **テロップ層**：語同期のカラオケ字幕コンポーネント（白極太＋強調色＋黄マーカー、下1/3）。
   - **寄りズーム層**：各ビートで話者にプッシュイン（`scale` interpolate）。無音カット/フィラー削除も。
   - **図解パネル層**：既存キット（kit2/kit の Card2/番号ステップ/フロー/ゲージ/DrawLine/StackTags 等）を**実写の上に**配置。台本の該当語で pop。
   - **SFX層**：`SfxTrack` を全出現に自動散布。
3. **区切り検出**：話題の変わり目で背景差し替え/BGMチェンジ/EDIT LOG風まとめ。
4. **仕上げ**：BGMベッド、キラッ転換、締めの集計パネル。

### 私たちのキットで「今すぐ再現できる／作り足す」切り分け
- ✅ 既にある：図解パネル全種（番号ステップ/フロー矢印/ゲージ=進捗バー/カレンダー的カード/ノード線=DrawLine/積み上げ/擬似カード）、SFX散布、スプリング登場、ケンバーンズ。
- 🔨 作り足す：①実写動画を下敷きにする土台コンポ（OffthreadVideo＋セーフエリア）②**語同期カラオケ字幕**ジェネレータ（whisper word tsからテロップ枚数を自動生成）③**話者オートズーム**（ビートごとpush-in）④無音/フィラー自動カット⑤BGMベッド＆区切り検出。
- ⚠️ 実写ならではの注意：話者の顔・手に図解を被せない（上1/3に置く）。テロップは下だがInstaのキャプション帯/いいね列は避ける（既存SAFE準拠）。

## 再現の進め方（提案）
1. まずユーザーから**短い喋り動画（10〜20秒でOK）**をもらう → word文字起こし。
2. 上記②〜④の土台コンポを実装し、その素材でテロップ＋寄り＋SFX＋図解1〜2枚を当てた**練習1本**をレンダー。
3. 見てもらって密度・色・SFX量を調整 → テンプレ化（talk-reel自動化）。

色・フォント・SAFEは既存規定を流用。図解の中身の色は自由（緑黄強制はしない＝ユーザー指定）。
