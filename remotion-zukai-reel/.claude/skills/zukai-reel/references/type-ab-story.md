# 型：AさんBさんストーリー（A家族 / B家族 比較ストーリー）★別型・高難度　2026-10-10

> 標準の「図解リール」とは**別ジャンルの型**。発想の元メモ＝`reel-study-family-cast.md`。
> 初弾テーマ＝**マイル（陸マイラー系）**。中身の制作は未着手。ここは“型”の保存のみ。

## これは何（目的）
- **2つの家族を並べて、同じ状況で選択と結果が分かれる**のを物語で見せる型。
  - **A家族**＝お金の勉強をする／情報を取りに行く → **得する**。
  - **B家族**＝何もしない・知らない・やらない（「マイル？よく分からん」）→ **損する**。
- 狙い＝**損失回避で自分ごと化**（「自分はB家族かも」と刺す）＋**シリーズ量産しやすい**（テーマを差し替えて横展開）。
- マイル版の骨子：A家族は制度・還元を知って旅行や生活費で得、B家族は知らずに取り逃す。

## 標準の図解リールとの違い（＝なぜ別型か）
- 標準＝1テーマを**図解で解説**（数字・グラフ・ツリー・テロップ同期）。主役は情報。
- この型＝**人物（家族）主役のストーリー対比**。図解は「2家族の差」を見せる脇役。
  場面が多く感情ドリブンで、**図解の作り込みが難しい**。だから**別管理**にする。
- **標準図解の中身・部品は一切崩さない**（既存リールはそのまま）。

## 構成の骨（ドラフト・確定前。制作時に台本から詰める）
1. フック：「同じ年・同じ収入。なのに数年で差がついた2つの家族」
2. 対比の反復：場面ごとに **A家族 → B家族** を左右 or 上下で並べ、選択と結果を出す
3. 山場：差が一番開く場面（貯まったマイル／旅行回数／浮いた金額 など）
4. 締め：「差は才能じゃなく“知ってるか”だけ」→ 保存／相談CTA
- 台本の声は手本（年収の壁・車）踏襲＝**一人称口語・つなぎで1本のストーリー・山場だけ厚く**。
  参考：`script-win-nenshu-kabe.md` / `script-study-good.md`。

## ビジュアル方針
- レイアウト・配色・フォント・背景は**うちのオリジナル**（他投稿の見た目はマネしない）。
- **A家族／B家族で色を固定**（例 A＝緑系＝得／B＝グレー〜コーラル＝損）。左右で陣営を固定。
- 家族キャラは**外部AI生成（太一）**。透過PNG・文字なし・被写体中央。表情違いを数点、固定で使い回す。
- 事実（マイル付与条件・還元率・改定など）は**リサーチ厳守・未確認は出さない**（`anthropic-skills:ai-office-research`）。特定カード名の断定的な推奨はしない。

## ★★混ざらないための分離ルール（最重要・恒久）
**1投稿＝専用ファイル一式＋専用プレフィックスで完全分離。既存投稿のファイルは絶対に編集しない。**
このプロジェクトは元々この方式（`nisa_*`／`kabe_*`／`infure_*`…）。それを厳守するだけで混ざらない。

- **コンポーネント**：この型は新規に `src/MileAbReel.tsx`（＋図解 `src/MileAbDesign.tsx`）を作る。
  `NisaSozokuReel`/`KabeReel` など**既存リールは触らない**。
- **型の部品は共有しない**：A/Bストーリー用のレイアウト部品は MileAb 側のファイル内に閉じる。
  標準図解の部品（`src/components/kit2.tsx` 等）を書き換えてこの型に合わせない（＝標準が汚れない）。
- **画像**：`public/gen/mile_*.png`（専用プレフィックス）。他プレフィックスと混在させない。
- **音声**：`public/mile_narration.wav` ＋ `mile_transcript.json`。
- **Root.tsx**：Composition を**1つ追加するだけ**（既存の行は変更しない）。
- **設計/画像指示書**：`assets/image_brief_mile.md` 等、専用ファイルで持つ。

→ こうすれば、この回のあと**「いつもの図解リールに直す／作る」時は標準の型・ファイルだけ**を使い、
  A/Bストーリーの部品は一切読み込まれず、**ぐちゃぐちゃにならない**。
  （迷ったら「今どの型か」を先に宣言 → その型の専用ファイルだけ触る。）
