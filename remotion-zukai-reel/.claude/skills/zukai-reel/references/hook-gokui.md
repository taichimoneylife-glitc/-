# ★★★冒頭（フック）の極意（たいちさん指定・2026-11-17）※リールの冒頭は必ずこれを読んでから作る

【冒頭（フック）の極意｜これを守って冒頭を作ってください】

■大前提
・発信者：保険代理店の営業・FP（26歳・子ども2人のパパ）。子育て世帯向けのお金のリール。
・今のリールは冒頭ですぐスワイプされる。「2秒」ではなく“見た瞬間”の1画面で止める。
・武器は3つ：①利益（メリット） ②損 ③危機感（恐怖）。どれかを冒頭でガツンと出す。
・社長の好みは「利益型より損失型」。

■基本の形
・1画面・3行・1行10文字前後。長い冒頭はNG。文字数を必ず数える。
・基本の3パーツ：「もし〇〇なら／〇〇しないと／〇〇損します」
  1行目＝自分ごとにする（当てはまる人が多い条件）
  2行目＝やることを予告（動作は1つ）
  3行目＝損失回避で止める（金額は根拠のある数字だけ）
・「もし」型だけに頼らない。毎回、型ごとに複数案を出す。
・トークの冒頭は「止める一言 → 続きが気になる一言 → 今回は〇〇を解説します」の3文。
  例：こどもNISA、教育資金目的はやめてください。／これを知らないと、後々後悔する可能性があります。／今回は、こどもNISAの概要と使い方を解説します。

■続きを見たくなる言い方（中身をバラさない）
・冒頭で理由や答えまで言わない。「なぜ？」「何を？」を残す。
・「ある仕組み」「これ」「後悔する可能性」など、中身を隠して本編で回収する。
・ただし引っぱりすぎない。本編の早いうちに必ず回収する（釣りに見えないように）。

■伸びるフックの型（型ごとに案を出す）
①常識破壊：常識と逆のことを言う（例：僕は家族旅行の飛行機代を現金で払いません）※社長が本当にしていることだけ
②視覚的な動き：最初の映像に動き（カードを差し出す、フレームインして話し始める）
③ターゲットコール：見る人を絞って呼ぶ（例：子ども2人いて、航空券が高くて旅行をあきらめた人）※狭めすぎない
④指示語：「これ」で中身を隠す（例：これ知らないだけで、家族旅行のたびに数万円損してます）
⑤時制：年月を入れて新しさを出す ※本当に変わった日付だけ。施行中か予定かを分ける
⑥パターン・インタラプト：いつもと違う場所・映像（外、空港、旅行先）
⑦トリプルフック：中身が3つあるなら、フックも3つ並べる（例：ボケなくなる食材、シワ予防の食材、紫外線予防の食材、全部紹介します）。どれか1つに興味があれば止まる
⑧冒頭なし：フックも導入もなく、いきなりステップ1から始める（例：まず緑の食材を食べたら、次は赤の食材）。ステップ1を見せると、2・3も見たくなる
⑨質問・予想させる：「どっちになるか、見てください」（比較・物語の投稿で使う）

■伸びている冒頭の例（型の参考）
・もし歯がなくなったら、これ申請しないと数十万円消えます
・400円払わないと年金7万2千円消滅します
・2026年9月、道路交通法が激変します
・これ知らないだけで年間60万円損します
・親を扶養に入れてない人、毎年10万円損します
・マイル知らないだけで／家族旅行のたびに／数万円損してます
・9月から今まで通り60km/hで走る人は、全員スピード違反になる可能性（損＋危機感）

■使わない・やってはいけない
・「衝撃でした」で始める → 知らない人が言っても伝わらない。使用禁止
・「〇〇を解説します」だけで始める → 損も危機感もない。解説しますはフックの後のつなぎにする
・対象を狭めすぎる（例：夫婦でNISAしている人だけ）→ 当てはまらない人がすぐ離れる
・「大損」「必ず〇倍」「絶対」など言い切り → 事実と違えば批判される。「〜の可能性」「後悔するかも」「例えば」で言う
・数字を作らない。倍率や金額は「例」として出し、条件は本編・図解・キャプションで回収する
・冒頭だけ強くして、後で結論を覆さない
・他の発信者の冒頭は型の参考だけ。テーマや言い回しをそのまま使わない

■保険の投稿の冒頭で守ること
・発信者は保険屋。「保険はいらない」「保険を減らせる」方向の冒頭にしない。
・逆張りは「保険の本当の使い方」「保険不要論の落とし穴」の方向で作る。
・不安をあおって保険の加入につなげない。

■出力のしかた
・1本のテーマにつき、型ごと（3パーツ型・常識破壊・ターゲットコール・指示語・時制・トリプルフック・冒頭なしなど）に複数案を出す。
・各案に「1画面目の3行（各行の文字数つき）」と「トークの冒頭3文」をセットで出す。
・どの型か、損・利益・危機感のどれかを各案に書く。

## こちらの反省（2026-11-17 更新型保険回）
- 「安いから入った保険／更新のたびに／保険料が上がります」と説明から入って「誰が止まるんだ」と言われた。冒頭は説明ではなく、言い切り（禁止・損・危機感）で「なんで？」を残す。
- 冒頭の後は「〇〇なのか、保険屋の目線で解説します。まず〜」と本文へつなぐ形はOK。
- ★（2026-11-17）**冒頭でテーマの名前（例：更新型の保険）をいきなり言わない。** 「この保険に入っている人、損してるかも」と中身を隠して興味を付け → どんな保険か説明 → 「その保険が『更新型の保険』です」と正体を明かす → 仕組みの説明 → 対策 → 締め、の流れにする。
- ★「なんで？」→ 説明、の形がよい。冒頭で「なんで？」を作り、本文の頭で答える。
- ★（2026-11-17 たいちさん決定）**「大損します」は冒頭の1画面目・トークの止める一言ではOK。** 「使わない言葉」の大損は、本編・図解での言い切りの話。本編では「この例では」「〜の可能性」で言う。

## ★冒頭づくりの手順（更新型保険回の反省・2026-11-17「冒頭づくりクソやな」）
### やってしまったこと
1. 説明から入った（「安いから入った保険／更新のたびに／保険料が上がります」）。言い切り・損・危機感がなかった。
2. 型の名前ごとに言葉を入れ替えて大量に出した（12案の表など）。なぜ止まるかを考えていなかった。
3. 伸びている例（「子供の大学費用を／そのまま払うと／大損します」）のリズムと仕組みを、見せられるまで使わなかった。
4. 数字（2倍近く）を調べずに冒頭に入れた。調べたら一般的な基準はなく、1.5〜2倍が複数の例と合う。
5. 冒頭を詰めている途中で、本文・全文を書いた。
### 次からの手順
1. 伸びている冒頭の例を1つ選び、「なぜ止まるか」を一言で言う（例：誰でもする普通の行動＝大学費用を払う、が損だと言われるから）。
2. テーマの中から「みんなが普通にしていること・思い込み」を探す（例：保険料はずっと同じ／更新の通知を読まずに続ける）。
3. それを伸びている例と同じリズム（〇〇を／そのまま〇〇と／大損します＝8・7・5文字前後）に入れる。テーマ名は隠す（その保険・ある保険）。
4. 出すのは3案まで。1案ずつ「なぜ止まるか」を1行で付ける。
5. 数字を入れるなら、先に調べて出典を確認してから。条件は「※年齢・性別・保障額・保険会社・商品によって違います」で回収。
6. 冒頭が確定するまで、本文は書かない。
