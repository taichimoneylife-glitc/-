## 1. 画面の型（5つ）＝これを切り替えるだけで飽きない
1. **本人だけ**（全画面・ゆっくり寄り）＝気持ち・つなぎ。テロップは胸のあたり（画面の中央より少し下）
2. **上下2分割**：上半分＝画面の録画・画像・図、下半分＝本人。**テロップは分かれ目のすぐ下**（y≈980）。いちばん多く使われる（約半分の時間）
3. **カード型**：本人の映像が角丸のカード（横長）に縮む。後ろ＝同じ映像を大きく・ぼかして・暗く。テロップはカードの中に大きく、**同じ言葉の巨大な影の文字が後ろを横に流れる**。「強い一言」の所（できない／100%／$0）
4. **空の背景のフロー図**：白→薄い紫のグラデーション。文字が1つずつ書かれ、細い縦線で次の文字へつながる。カメラが下へ流れて次へ（マーケ博士の地図の動きと同じ考え方）。キーワードに赤い手書きの下線。**テロップは出さない（図の文字がテロップの代わり）**
5. **全画面の図解**：本人を消して図だけ（アニメの見本・コマ）。テロップは図の下

## 2. テロップ
- **1回に2〜4語だけ**（短い）。1行。極太・白・やわらかい影。大文字（日本語なら、短く切る）
- 言葉は話した順に1つずつ出る。前の語は消えずに、区切りごとに入れかわる
- 位置は画面の型で変わる（全画面＝胸、分割＝分かれ目の下、カード＝カードの中）
- 数字は**別に大きく**（緑の極太、本人の胸の前にカウントアップ）

## 3. 切り替え
- ほとんどが**カット**（切りかえ）。カード型だけ「縮んで入る」
- 2〜4秒ごとに画面の型が変わる。同じ型が5秒以上続かない
- 大事な一言は「白黒」にして目立たせる

## 4. 締め
- 文字だけの画面を2枚（「詳しくはYouTube」→「ZEROとコメントでリンク」）。ほかの物を置かない
