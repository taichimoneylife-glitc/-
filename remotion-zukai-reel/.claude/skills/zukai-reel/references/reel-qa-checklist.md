# リール品質ルール＆出す前セルフチェック（絶対厳守）

ユーザーが強く指摘。これを守らない動画は「20点」。毎回これに通してから出す。

## 1. 見えない/被る"禁止ゾーン"（Instagram Reel・1080×1920）
主要素・テロップ・数字を**ここに置かない**：
- 上部：ユーザー名バー等 → **y 0〜240**
- 下部：キャプション帯（本文・音源表示） → **y 約1500以降**（下から約420px）
- 右下：いいね/コメント/シェアの縦アイコン列 → **x>850 かつ y 1150〜1520**
- 画面の端：左右上下に最低48pxの余白
→ **使える安全域は x48〜1032／y 250〜1480**。テロップもグラフも主役はこの中。

## 2. テロップ（字幕）
- 位置は**下の安全帯＝y 約1330〜1460に固定**（それより下は禁止ゾーン＝見えない）。
- **中央寄せ**。1行は**全角18文字前後まで**。長ければ意味の切れ目で改行（`<br>`）。
- **孤立1文字で改行しない**（「増加」の「加」だけ次行…はNG）。折り返し幅を制御する。
- 太字・大きめ・半透明プレート or 縁取りで、どんな背景でも読める。
- 他の要素（グラフ・イラスト・見出し）と**絶対に重ねない**。

## 3. レイアウト＝ゾーンを分ける（被り厳禁）
1画面を縦に分割して配置：
- **見出し**：y 250〜360
- **メイン視覚（グラフ or イラスト or 図解）**：y 380〜1300（この中でさらに被らないよう配置）
- **テロップ**：y 1330〜1460
→ グラフと文字、画像とテロップが重なったら**即やり直し**。要素を減らすか、位置/サイズを変える。

## 4. 常時モーション（静止NG＝構成ミス）
- **喋っているのに画が止まっている瞬間を作らない。**
- 全イラストに常時 Float（ゆらぎ）。グラフ/図解は**常時ゆっくりズーム or ドリフト**。
- 要素は順次（ポンポン）出現。数字はカウントアップ、バーは伸びる、矢印は描かれる。
- 1画面に「出続けて動く主役」を必ず1つ以上。無音の静止＝設置/構成ミス。

## 5. 文字
- 改行・中央寄せ・折り返し幅を必ず整える。孤立文字・不自然な改行を作らない。
- 文字化け（□/豆腐/�）を出さない。日本語フォントが効いているか確認。

## 6. ★出す前セルフチェック（必須・毎回）
通しレンダーの前に、**静止画を各シーン複数フレーム書き出して目視**し、全部OKか確認：
- [ ] 文字化けなし（□や�が無い）
- [ ] 文字の被りなし（グラフ×文字／画像×テロップ／見出し×要素）
- [ ] 改行・中央寄せが自然（孤立1文字なし）
- [ ] テロップ・主要素が**禁止ゾーンに入っていない**（下すぎ/端/いいね列）
- [ ] 常に何かが動いている（静止ページが無い）
- [ ] イラストは十分か（スカスカでないか）
- [ ] 尺と音声がずれていないか
NGが1つでもあれば**直してから**通しレンダー。確認せずに出さない。
