# リール品質ルール＆出す前セルフチェック（絶対厳守）

ユーザーが強く指摘。これを守らない動画は「20点」。毎回これに通してから出す。

## 1. 見えない/被る"禁止ゾーン"（Instagram Reel・1080×1920）
主要素・テロップ・数字を**ここに置かない**：
- 上部：ユーザー名バー等 → **y 0〜240**
- 下部：キャプション帯（本文・音源表示） → **y 約1500以降**（下から約420px）
- 右下：いいね/コメント/シェアの縦アイコン列 → **x>850 かつ y 1150〜1520**
- 画面の端：左右上下に最低48pxの余白
→ **使える安全域は x48〜1032／y 250〜1480**。テロップもグラフも主役はこの中。

## 2. テロップ（字幕）
- 位置は**下の安全帯＝y 約1330〜1460に固定**（それより下は禁止ゾーン＝見えない）。
- **中央寄せ**。1行は**全角18文字前後まで**。長ければ意味の切れ目で改行（`<br>`）。
- **孤立1文字で改行しない**（「増加」の「加」だけ次行…はNG）。折り返し幅を制御する。
- 太字・大きめ・半透明プレート or 縁取りで、どんな背景でも読める。
- 他の要素（グラフ・イラスト・見出し）と**絶対に重ねない**。

## 3. レイアウト＝ゾーンを分ける（被り厳禁）
1画面を縦に分割して配置：
- **見出し**：y 250〜360
- **メイン視覚（グラフ or イラスト or 図解）**：y 380〜1300（この中でさらに被らないよう配置）
- **テロップ**：y 1330〜1460
→ グラフと文字、画像とテロップが重なったら**即やり直し**。要素を減らすか、位置/サイズを変える。

## 4. 常時モーション（静止NG＝構成ミス）
- **喋っているのに画が止まっている瞬間を作らない。**
- 全イラストに常時 Float（ゆらぎ）。グラフ/図解は**常時ゆっくりズーム or ドリフト**。
- 要素は順次（ポンポン）出現。数字はカウントアップ、バーは伸びる、矢印は描かれる。
- 1画面に「出続けて動く主役」を必ず1つ以上。無音の静止＝設置/構成ミス。

## 5. 文字
- 改行・中央寄せ・折り返し幅を必ず整える。孤立文字・不自然な改行を作らない。
- 文字化け（□/豆腐/�）を出さない。日本語フォントが効いているか確認。

## 6. ★出す前セルフチェック（必須・毎回）
通しレンダーの前に、**静止画を各シーン複数フレーム書き出して目視**し、全部OKか確認：
- [ ] 文字化けなし（□や�が無い）
- [ ] 文字の被りなし（グラフ×文字／画像×テロップ／見出し×要素）
- [ ] 改行・中央寄せが自然（孤立1文字なし）
- [ ] テロップ・主要素が**禁止ゾーンに入っていない**（下すぎ/端/いいね列）
- [ ] 常に何かが動いている（静止ページが無い）
- [ ] イラストは十分か（スカスカでないか）
- [ ] 尺と音声がずれていないか
NGが1つでもあれば**直してから**通しレンダー。確認せずに出さない。

## 自己レビューで見つけた“安っぽさ”と直し方（暴落リール 2026-10-20／太一OK済みの型）
> 書き出したら必ず「0.5秒ごとのコマ一覧」を作って、下の表で採点してから送る。

| よくある失敗 | 直し方（BourakuReel.tsx に実装済み） |
|---|---|
| 1場面に要素を詰め込む（地球儀＋国旗＋数字×3＋スタンプ…） | **1ページ1主役**。場面の中を `Page`（ぼかし＋ズームで入れ替え）で分け、主役は大きく。数字は `Hero`（200px級）で |
| 山場が地味（細い線＋小さい絵） | 山場だけ演出を盛る：**画面ゆれ `useShake`・赤フラッシュ・ドン系SE（dadan/thud）・暗転＋巨大テロップ**、キャラを下から出す |
| 転換が全部同じ | `Scene` の inT/outT を意味で使い分け：whip（基本）／drop（落ちる話）／punch（山場）／zoom（締め） |
| 字幕が全部同じ見た目 | `Captions`：`*語*`＝緑、`!語!`＝赤、`~語~`＝青で**キーワードだけ大きく＋マーカーが声に合わせて伸びる**。長い行は自動で縮める |
| 図解の一部だけカード、他は素置き | カード（白・角丸34・影）で揃える。グラフ・比較・自分の話はカードに入れる |
| 締めにキメがない | 最後は黒い帯に黄色の大きい文字（例「罪悪感なく 使える」）＋キャラ＋高音SEを1回 |
| SEのポン連打 | 同じ音は場面に2〜3回まで。連続物（コイン等）は間引く。キメの音（u05/u10/dadan）だけ強く |
| キャラがいつも同じ入り方・無言 | 左右・下から出し分け。`talk` 指定で**ナレの音量に合わせて口パク**（`bourakuMouth.ts` を音声から自動生成） |
| 注記が小さすぎる | 24px以下は読めない。短くして26〜28px、1行で |
| 数字が「何年に1回」など言い切れない | 出典で確定できる数字だけ（例：MSCI ACWI 47カ国・約2,500社・年4回見直し、2008年−56%・2020年−34%）。画面に「※」で出典 |
| シーソー等の向きを逆にする | 「重い側が下」を必ず静止画で確認（rotate の符号を毎回チェック） |
| 「分散」を抽象的に描く | 視聴者が実際に持っている商品名（全米株式・全世界株式・日経平均）を並べ、**中身＝株**のタグ→3本を重ねて**一緒に落ちる**、で想像させる |
| 太一キャラの量 | 基本は図解がメイン。**箇所数は決めない（臨機応変）**。本人が語る所（「僕は」「僕自身も」・締め）は口パク、山場はリアクション（頭を抱える等）。暴落リールv11が太一OKの例 |
