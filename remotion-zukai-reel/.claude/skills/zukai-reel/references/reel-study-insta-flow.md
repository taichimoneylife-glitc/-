## 全体構成（STEP積み上げ×1本の連結フロー）
1. **0–8s 実写フック**：白背景の実写トーク。上に**🚫赤い禁止丸**を重ね、黒太字＋赤で「コレをやるまで／絶対に投稿しないで」。指差し。＝損失回避×好奇心フック。
2. **12s– 白い固定タイトル帯**「インスタ運用の方法」（上部に常駐）＋**専門家キャラ（白衣CEO）がカードで主張**：「投稿が伸びることはあくまで手段であり、何の商品を売るのかの目的から逆算して投稿作りをすることが重要」＝権威づけ＋結論先出し。
3. **24s– 連結フロー構築**：縦スパイン(中央線)に沿って上から下へ要素が積み上がる。
   - 横アイコン行「運用 → バズらせる → バズる → 収益化」。
   - **大きな赤✕スタンプ**で「バズらせる／バズる」を否定（＝バズが目的化するな）。
   - 「とにかくバズる」に✕。
   - 人アイコン＋**側吹き出し2つ**：「目的：フォロワーを増やす」(赤✕) / 「目的：収益・集客に繋げる」(**ピンク枠＝正解**)。
4. **STEP1〜5（オレンジのタブ見出し）で章立て**、各STEPがフローで展開：
   - **STEP1 商品の決定** → 分岐ツリー：アフィリエイト / PR / コンテンツ販売 / 作る商品。
   - **STEP2 リサーチ先の決定** → 「誰が欲しい？」→ ターゲット設定。
   - **STEP3 現状・ゴール** → 「現在地」↔「目標」の**before→after**（例アイコン：3日坊主／ダイエット／自信をつける＋**棒グラフ上昇**）。
   - **STEP4 投稿内容の決定** → 現状→(**赤い矢印**)→ゴール。例「継続しやすいダイエット法（痩せレシピ／宅トレ／スケジュール管理）」をピンク帯で。
   - **STEP5 投稿の量産** → **スマホ実機モックを横5枚**（実リールのサムネ＋再生数19.6万/7.1万…）→ 各下に**ターゲットの人アイコン列**→ フロー終端「商品を購入」(赤帯)。

## 盗む図解の語彙（＝引き出しに追加）
- **🚫損失回避フック**：実写に赤い禁止マーク＋「コレをやるまで〜しないで」。見た瞬間に止める。
- **専門家キャラの主張カード**：結論を人物カードで先出し＝権威・安心（保険屋＝太一さんに転用可）。
- **1本の縦連結フロー（スパイン＋横アイコン行＋矢印）**：話の全体を1本の線でつなぐ（ユーザーが一番好きな"連結図解"の大規模版）。
- **大赤✕スタンプで"間違い"を否定＋側吹き出しで正解をピンク強調**：誤解崩し（うちの `Myth`/IgTree と同系統・より大胆）。
- **STEPオレンジタブで章立て**：手順ものを「STEP1〜」で明示（`reel-study-yunagi`のファイルタブ式と同じ思想）。
- **分岐ツリー**：1つの決定から選択肢を枝分かれ。
- **現在地→ゴールの before→after＋棒グラフ上昇**：変化を1画面で。
- **赤い矢印で動線**：現状→ゴールの流れを赤矢印で誘導。
- **スマホ実機モック横並び＋下にターゲット人アイコン**：「量産→リーチ」を具体で見せる（CTA/量の可視化）。
