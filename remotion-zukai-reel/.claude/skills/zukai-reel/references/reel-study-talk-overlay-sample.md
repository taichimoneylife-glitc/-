# 参考：トークリール自動編集の実例（実写＋上部オーバーレイパネル）

> ソース：太一さん提供の画面収録（X/Twitterで再生中のトークリール・1180×2556・60fps・18s）。2026-10-06 実フレーム解析。
> 用途：今後【太一さんのトークリールを動画編集】する際の編集スタイル基準。`reel-study-talk.md`／`talk-reel-pipeline.md`／実装`src/TalkReel.tsx`と合わせて使う。
> テーマ例「Claude/AIが動画編集の“常識”を変えた」。※内容ではなく"編集の型"を学ぶ。

## レイアウト（確定イメージ）
- **下＝実写トーク**（話者・上半身・黒T、カメラ目線）。顔・手に図解を被せない。
- **上＝図解オーバーレイパネル**（話に合わせて切替）。
- **寄りズーム**（話者に時々プッシュイン）＋常時わずかな動き。
- ※今回のソースはX再生画面なので、上下のXアプリUI（おすすめ/フォロー中タブ・いいね数・アカウント名）はリール本体ではない＝無視。

## オーバーレイの語彙（盗む）
1. **案A〜案Eの"選択肢カード"**：大きく「案A」黒太字＋サブ見出し（例 案A「編集前→編集後」／案C「AEが勝手に埋まる」／案D「Claudeに」／案E「指示1つで完成」）。手順・比較を章立てで見せる。
2. **before→after表記**：「撮影したままの素材 → 完成形へ切り替え」。素材と完成を対比。
3. ~~グリーンバック撮影のカットイン~~ → ★太一さんは**グリーンバックは使わない**（2026-10-06指定）。実写はそのまま（通常背景）で編集する。別ショットのカットインが要るなら通常撮影のカットで。
4. **UI風カードの横並び**：「撮影素材」「Claudeが動画編」などをアプリUIふうカードで並べる（擬似UI）。
5. **タイムライン／波形風パネル**：編集ソフト(AE)のタイムラプスをUIパネルで表現。
6. **赤い取り消し線で否定→言い換え**：「常識」に赤の取り消し線＋「常識を変えました」。＝否定演出（インスタ運用リール `reel-study-insta-flow.md` の赤✕と同じ思想）。
7. **語同期テロップ**（下部）＋**出現ごとSFX**＋**BGMベッド**（talk-reel-pipelineの基本）。

## 自動化の当てはめ（我々のパイプライン）
- 下敷き＝`OffthreadVideo`で実写、下1/3＝語同期カラオケ字幕、上1/3＝上の図解パネル（既存`kit2.tsx`/`kit.tsx`の擬似UIカード・STEPタブ・before/after・ノード線で再現）、話者オートズーム、出現SFX。
- 案A〜Eは**STEPタブ or 番号カード**で、before→afterは**2カード＋矢印**で、否定は**赤取り消し線/✕スタンプ**で実装（色は自由）。
- 詳細手順は `talk-reel-pipeline.md`（解析→秒数設計表→Remotion生成→確認→書き出し）。実装雛形 `src/TalkReel.tsx`。
- 顔・口・手に被せない。InstaのUI領域（右下いいね列・下キャプション帯）を避ける。

## 太一さんのトークリール編集・標準フロー（今後）
1. 太一さんが喋り動画（素材）＋（あれば）台本/文字起こしを渡す。
2. こちらで：無音/フィラーカット→語同期字幕→上部図解パネル（案/比較/否定/before-after）→寄りズーム→SFX/BGM→確認静止画→書き出し。
3. 図解の型は内容の情報量で選ぶ（少→1画面完結、多→縦連結フロー）。トークは上部パネルで補強。
