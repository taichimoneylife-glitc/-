## 使う所：最後のCTA（64.75〜69.0）
声：「プロンプト本体と画面付き解説が欲しい人は／好きな色をコメントして／受け取ってください」
- **画面割り**：上 約55%＝配る資料（白いカード・角丸・影）／下 約45%＝話す本人。境目は白→映像のグラデーション
- **カードの中身が下から上へ流れ続ける**（4秒で約10ページ分）：表紙（オレンジの「プレゼント」札＋題名＋「✓①〜⑤を画面つきで解説」「✓コピペで使えるプロンプト」「✓設定できたか確かめる方法」「✓画面写真8枚」）→ 各ページ（見出し＋実際の画面写真）。**量があること・本当に作ってあること**を見せる
- **テロップ3段**：①「〇〇が欲しい人は」（黒）→ ②「好きな色をコメントして」（オレンジ・一番大事）→ ③「受け取ってください」（黒）
- 口調：「〇〇が欲しい人は／〇〇とコメントして／受け取ってください」の3拍

## 太一版（ctaComment.tsx の CommentCta）
- 本人の実写 → **太一のイラストが口だけ動く**（下・横290〜790）
- カード（横150〜930・縦300〜960）の中：**実際に作った図解スライド**が流れる → **インスタのコメント欄**にキーワードを打って「送信」→ **公式LINEの画面**に横スライドで切り替わり、「コメントありがとうございます！」＋「受け取る ▶」のカードをタップ
- テロップ（縦992）：「〇〇が欲しい人は」→（赤）「「〇〇」とコメントしてね」→「公式LINEで受け取ってください」
- 渡すもの：want／keyword／title／chips／pages（実際のスライド画像など）／tComment／tLine／mouth（口の動き）
- LINEのロゴは使わない（緑の文字と吹き出しだけ）
