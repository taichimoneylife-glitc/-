# 投稿の「型」レジストリ（固定）　2026-10-10

> 新規投稿は、まず**どの型か**を宣言してから作る。**1投稿＝専用コンポーネント＋専用画像プレフィックス**で完全分離し、他の型・他の投稿のファイルは触らない。これでごちゃ混ぜを防ぐ。

## 型1：図解リール1（標準・いつもの・デフォルト）★固定
- これが「いつもの図解リール」。アフレコ音声に完全同期した**全画面フラットイラスト図解**（数字・グラフ・ツリー・テロップを声に合わせて1つずつ出す）。
- 中心ドキュメント：`SKILL.md` ＋ `edit-directives.md`（累積ディレクティブ）＋ `diagram-patterns.md`（図解カタログ）。
- 実例コンポーネント：`NisaSozokuReel`/`NisaSozokuDesign`、`KabeReel`、`InfureReel`、`CarReel` 等。
- 迷ったら・指定がなければ**この型1**。

## 型：AさんBさんストーリー（別型・高難度）
- A家族=勉強して得／B家族=何もせず損 を物語で対比（損失回避で自分ごと化）。初弾テーマ=マイル。
- 標準の図解解説とは別ジャンル。詳細・分離ルール：`type-ab-story.md`。

## 運用ルール（恒久）
1. 投稿を始める時、**型を先に決める**（例「型1でいく」「AさんBさん型でいく」）。
2. その型の**専用ファイルだけ**を作る/触る。既存投稿・他型のファイルは編集しない。
3. 画像＝専用プレフィックス（`nisa_`/`kabe_`/`mile_` …）、音声＝`<name>_narration.wav`、`Root.tsx`は1行追加のみ。
4. 新しい型が増えたら、ここに追記して番号・名前を固定する。
