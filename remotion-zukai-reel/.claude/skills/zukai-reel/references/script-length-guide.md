# 台本ガイド＝文字数とメリハリ（車リール=伸びた基準の実測）★確定

> 台本を書く／直すとき、各パートの文字数を**この基準**に当てる。車リール（約70秒・伸びた）を実測して作成。
> 文字数＝「内容文字」（句読点・記号・スペースを除いた実質の字数）でカウントする。

## 実測ベンチマーク（車リール 70.1秒）
- 合計 **417字 / 9パート**、平均 **46字/パート**、ペース **約6字/秒**。
- 内訳：標準パート 35〜42字（軽く流す）／**山場は78〜85字（＝平均の約1.8倍にドカンと厚い）**／締め 22字（短く言い切り）。
- 山場は**1〜2個だけ**（車＝「計画性85字」「逆転の数字78字」）。全部を厚くしない。

## 目安（新しい台本はこれに合わせる）
- **1パート（図解1枚＝VO）＝40〜65字**を標準に。
- **山場（この回いちばん刺す1〜2枚）＝75〜90字**に厚くする。山場＝意外性/逆転/損得の決め所。
- **転換・助走・説明だけの枚＝35〜45字**に軽くする。
- **フック＝40〜60字**、**締め＝20〜35字**（短く言い切り）。
- 尺の見積り：内容字数 ÷ 6字/秒 ≒ 秒数（例：図解パート480字→約80秒）。

## ★流れる口語でも“タイト”に（長文段落にしない）
「つなぎ・口語にする」＝長く喋る、ではない。**車リールは流れてるのに1パート約46字＝1〜2文**。
- 1パート＝**1〜2文**まで。4〜7文の段落を書いたら即アウト（「長々話してて聞きづらい」の正体＝投資②v6の失敗）。
- 接続詞・体験・たとえは“1語/1フレーズ”で効かせる。説明を足すより削る。
- 書いたら各パートの文の数を数える：標準1〜2文・山場でも3文まで。

## ★最重要＝メリハリ（フラット禁止）
- **全パートを同じ長さにしない**。車が伸びたのは緩急があったから。
- 設計時に「**どこが山場か**」を先に1〜2枚決める→そこだけ厚く、他は軽く。
- 山場と標準の差が小さい（全部60字前後で平坦）＝**どこで盛り上がるか分からない**＝離脱。これが“物足りない/眠い”の正体。
