# こどもNISA 事実メモ（2026-11-17 WebSearch で確認）

| 項目 | 内容 | 出典の強さ |
|---|---|---|
| 開始 | 2027年1月（2027年1月1日以降に開設した口座から） | ②複数一致（大綱にもとづく） |
| 対象 | 0〜17歳（出生した年も対象） | ②複数一致 |
| 使える枠 | つみたて投資枠のみ（成長投資枠は18歳から） | ②複数一致 |
| 買い方 | 定時・定額の積立（一括購入は想定されていない） | ②（セゾン投信・解説記事） |
| 限度額 | 年60万円・非課税保有限度額600万円 | ②複数一致 |
| 大人の枠との関係 | 600万円は大人の生涯枠1,800万円に含まれる（別に2,400万円にはならない）※「予定」と書く記事あり | ②複数一致・公式原文は未確認 |
| 18歳 | その年の1月1日に18歳の年から、自動で大人のNISAへ移る（成長投資枠も使えるようになる） | ②野村證券 |
| 払出し（12歳まで） | 原則できない（災害などの例外） | ②（竹川美奈子 note）・災害例外の原文は未確認 |
| 払出し（12歳から） | 使い道が子のためのもので、子が同意した書面を付けて、親権者等が申出書を出す | ①金融庁資料（fsa.go.jp/access/r7/270/270_03.pdf） |
| 証券会社の変更 | 18歳未満の間は変えられない（依頼文より） | 未確認（次に使うとき調べる） |
| 計算例 | 月5,000円×18年：元本108万円・年5%で約175万円／月1,000円×18年：元本21.6万円・年5%で約34.9万円（月複利・税引前） | 自分で計算 |
