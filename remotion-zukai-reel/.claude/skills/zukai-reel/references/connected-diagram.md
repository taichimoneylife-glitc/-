# 連結図解の型（線でつなぐ・吹き出しがポン）※ユーザーが一番好きな編集

過去に評価が高かったのはコレ＝**線でつながっていく図解**（車リール・投資の三大原則）。
バラバラに置くのではなく、**中心(ハブ)や起点から線が伸び、その先に要素(カード/吹き出し/アイコン)がポンと出る**。

## 型A：ハブ&スポーク（中心→周り）
- 画面中央にテーマ（タイトル or 中心アイコン/キャラ）。
- そこから**線（DrawLine）が放射状に伸び**、先端に**カード/アイコン**がPopInで出現（線が届いた瞬間に）。
- 例：投資の三大原則＝盾→線→長期/積立/分散の3カード。がんの備え＝中心→診断/治療/収入減 等。

## 型B：フロー（左→右／上→下で因果・順番）
- 起点→線/矢印→次→…と**順番に伸ばして**ストーリーを作る。
- 例：撮影→Claude→自動編集／がん＝診断→治療→収入減→備え。

## 型C：吹き出しがポン（線の先に一言）
- アイコンや人から**引き出し線**を引いて、先に**吹き出しテロップ**を出す（注釈・感情・数字）。
- 例：棒グラフの該当バーから線→「約2.4倍」吹き出し。貯金グラフから線→「終わりが見えない」。

## 実装（Remotion）
- 線：`DrawLine d="M x1 y1 L x2 y2" delay dur` で**描画アニメ**（stroke-dashoffset）。放射は複数DrawLineを少しずつdelayずらし。
- 先端ノード：線のdur終了あたりで `PopIn delay` → カード/アイコン/吹き出しがポン。順次（ポンポン）。
- 常時：各ノードに Float、全体に緩ズーム。線→ノードの連鎖で「組み上がっていく」感を出す。
- 参考実装：`src/ToushiReel.tsx` P1（盾→線→3カード）、`src/scenes/BoxTree.tsx` / `CarMindMap.tsx`（箱を線でつなぎ1画面に組み上げる）。

## 使いどころ（毎回どれか入れる）
- 各リールに**最低1枚は連結図解ページ**を入れる（バラ置きだけにしない）。
- 中心テーマの分解、流れ（因果・時系列）、注釈(吹き出し)に使う。
- 色・カード・薄黄は既存規定どおり。線は ink か green、太さ6〜10。
