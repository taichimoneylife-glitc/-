# 参考⑩：AIアニメ動画の比較（ケンジと萌・車）96秒・720x1280

## 作り方（見て分かったこと）
- 絵はアニメ調のAI画像。それを **画像→動画AI**（Kling / Veo / Runway / Hailuo などの類）で 3〜6秒ずつ動かしている。
  歩く・振り向く・手が契約書を差し出す・湯気・カメラが寄る、が本当に動いている（静止画のズームではない）。
- 1カット＝1文。白い明朝っぽい字幕を画面の真ん中に。図解はほぼ無く、絵の中の小道具（契約書・返済ボックス・スマホ画面・積立元本の札）が数字を見せる。
- 同じ2人（顔・服を固定）を全カットで使う＝キャラ固定が命。

## 流れ（参考⑦の「同条件 → 分かれ道 → 数年後 → 教訓」と同じ骨組み）
1. 前提：2人とも150万円・収入も条件も同じ（0〜10秒）
2. 分かれ道：ケンジ＝1,200万円の車・72か月・年利8%・月18万円／「車はみんなローンで買うもの」
3. 萌＝150万円の中古車を現金 → 毎月18万円をインデックス積立
4. 6年後：ケンジ＝6年落ち・貯金なし・また新車が欲しい／萌＝積立元本 約1,300万円（18万×72）・同じ中古車
5. 教訓：同じ6年でも手元に残るものが違う／車は値下がり・投資は値上がりを期待／資産を先に、値下がりする物は後で
6. CTA：NISAを始めるならプロフィール → 保存とフォロー

## うちで再現するなら
- Remotion だけでは「歩く・手が動く」は作れない。動く素材はユーザーが画像→動画AIで作る。こちらは：台本・カット割り表・
  各カットの画像プロンプト＋動きプロンプト・字幕・数字の札・効果音・つなぎ・音声合わせ を担当。
- 動画AIなしの代わり：静止画＋寄り/パン・前後の層ずらし・まばたき/口パク・湯気などの小さな動き（リアルさは落ちる）。
