# 参考⑩：AIアニメ動画の比較（ケンジと萌・車）96秒・720x1280

## 作り方（見て分かったこと）
- 絵はアニメ調のAI画像。それを **画像→動画AI**（Kling / Veo / Runway / Hailuo などの類）で 3〜6秒ずつ動かしている。
  歩く・振り向く・手が契約書を差し出す・湯気・カメラが寄る、が本当に動いている（静止画のズームではない）。
- 1カット＝1文。白い明朝っぽい字幕を画面の真ん中に。図解はほぼ無く、絵の中の小道具（契約書・返済ボックス・スマホ画面・積立元本の札）が数字を見せる。
- 同じ2人（顔・服を固定）を全カットで使う＝キャラ固定が命。

## 流れ（参考⑦の「同条件 → 分かれ道 → 数年後 → 教訓」と同じ骨組み）
1. 前提：2人とも150万円・収入も条件も同じ（0〜10秒）
2. 分かれ道：ケンジ＝1,200万円の車・72か月・年利8%・月18万円／「車はみんなローンで買うもの」
3. 萌＝150万円の中古車を現金 → 毎月18万円をインデックス積立
4. 6年後：ケンジ＝6年落ち・貯金なし・また新車が欲しい／萌＝積立元本 約1,300万円（18万×72）・同じ中古車
5. 教訓：同じ6年でも手元に残るものが違う／車は値下がり・投資は値上がりを期待／資産を先に、値下がりする物は後で
6. CTA：NISAを始めるならプロフィール → 保存とフォロー

## うちで再現するなら
- Remotion だけでは「歩く・手が動く」は作れない。動く素材はユーザーが画像→動画AIで作る。こちらは：台本・カット割り表・
  各カットの画像プロンプト＋動きプロンプト・字幕・数字の札・効果音・つなぎ・音声合わせ を担当。
- 動画AIなしの代わり：静止画＋寄り/パン・前後の層ずらし・まばたき/口パク・湯気などの小さな動き（リアルさは落ちる）。

## 台本（文字起こし・たいちさん提供 2026-11-12）
健二と萌が車を買うためにそれぞれ150万円を貯めたとします。収入も条件も同じです。でも2人が選んだ車は違いました。
健二が選んだのは1200万円の車です。ローンは年利8%で、返済期間は72ヶ月、頭金に150万円を払い、6年間毎月約18万円を返済します。
車はみんなローンで買うもの、健二はそう思っていました。
一方萌は150万円の中古車を現金で買いました。見た目は地味でも移動には十分です。萌は健二の返済額と同じく、毎月約18万円を手数料の低いインデックスファンドに積み立てます。
6年後健二の車は6年落ちです。貯金はなく、また新しい車が欲しくなっているでしょう。萌は同じ中古車に乗り続けています。
6年間で積み立てた元本は約1300万円。同じ6年でもお金の使い方で手元に残るものは大きく変わりました。
車は値下がりし投資した資産には値上がりを期待できます。ここで大事なのは買う順番です。値上がりを期待できる資産を先に買い値下がりするものは後で買う。経済的な自由に近づくには今あるお金の使い方を変えることも大切です。NISAを始めるならプロフィールをチェック。忘れないように保存とフォロー。

## 数字の検算
- 1,050万円（1,200万−頭金150万）・年8%・72回 → 月184,099円（約18万円）✓／利息の合計 約276万円
- 18万円×72か月＝1,296万円（約1,300万円）✓ ← 運用益を入れず「元本」だけで比べている

## なぜ伸びたか（要点）
1. 冒頭5秒で「同じ条件の2人」＝結末が気になる物語。名前があるので自分ごとに。
2. 変える所は1つだけ（車の値段）。比べる軸が1本なので一瞬で分かる。
3. **同じ月18万円の行き先が違う**、が核。返済に消える18万 vs 積立に残る18万。
4. 結果は「元本 約1,300万円」だけ＝利回りの仮定ゼロ → 突っ込めない、でも数字は大きい。
5. 「車はみんなローンで買うもの」＝よくある思い込みを置いて、6年後に崩す（参考⑦と同じ「安心→崩す」）。
6. 極端な設定（1,200万の車・8%）がコメントを呼ぶ（「誰が買うねん」「8%は高すぎ」）→ 反応が増える。
7. 感情の絵：健二＝うなだれる・また新車が欲しい／萌＝穏やか。損をしたくない気持ちに刺さる。
8. 持ち帰れる1行の原則：「値上がりする資産が先、値下がりする物は後」→ 保存・シェアされる。
9. 講義ゼロ・1カット1文（2〜3秒）・過去形の絵本口調（〜しました）。
10. CTAが軽い：NISAならプロフィール／忘れないように保存とフォロー。

## うちで使う型
同じ条件の2人 → 1つだけ違う選択 → 同じ月額の行き先が違う → ○年後を「元本」で比べる → 思い込みを崩す → 原則1行 → 軽いCTA
