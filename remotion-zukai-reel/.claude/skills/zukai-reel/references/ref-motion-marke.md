# 参考リール（マーケ博士「インスタのAIが出した3つの必須設定」73秒）の動き分析

1秒1コマ＋転換部分は0.1秒ごとに見た結果。デザイン（色・キャラ）はまねせず、**動きと見せ方の型**だけ取り入れる。
部品は `src/components/cam.tsx`（Camera / Spot / Callout / ghostIn / SpeedLines）。

## 1. 画面全体が「1枚の大きな紙」＋カメラ
- 場面の中では切り替えない。**カメラが寄る・引く・横に流れる**だけで次の説明に進む。
- 動きは **3〜8フレーム**。最初ためて一気に動き、ピタッと止まる（ease: bezier(0.7,0,0.18,1)）。
- 動いている間（2〜3フレーム）だけ少しぶれる（ブラー）。止まったらくっきり。
- 例：スマホ全体 → 右上の三本線へ2倍で寄る（13.2–13.4秒）→ 一瞬で引く（15.7–15.9秒）→ 下のスイッチへ寄る（19.1–19.3秒）。
- ツリーの見出し → 1つの枝へ寄って、そこから次の場面へ（11.1–12.5秒）。

## 2. 注目の所だけ明るく（スポット）
- 画面全体（見出し・キャラも）が**3〜4フレームで暗く**なる。注目の所だけ明るいまま、**黄色の太い枠＋ぼんやり光る**。
- 暗くなるのは「ここを見て」の瞬間だけ。説明が終わると明るく戻る。
- 「最悪の場合…」のような山場は、画面全体を真っ暗にして白文字＋ハンコ（63–65秒）。

## 3. 引き出し線つきの説明
- 注目の所に**黄色い点** → **線が4フレームで伸びる** → 説明の箱。
- 箱は白、黒の太い枠、**ぼかさない影（右下にずらしただけの影）**。キーワードだけ色を変える。

## 4. 出方：うっすら大きめ → くっきり
- 新しい箱・見出しは、1〜2フレームだけ**うすく少し大きく**出て、次のフレームでくっきり正しい大きさに。ポップより上品で速い。
- 消える時も一瞬うすくなって消える（50.4秒の吹き出し）。

## 5. 場面の頭
- **集中線**が一瞬出る → 小さい「道順の札」（例：右上の三本線→コンテンツ設定）→ 大きな見出し → 図。0.3秒で全部そろう。
- 大きな区切りは**背景の色ごと変える**（明るい紫 → 青）。

## 6. キャラ
- 画面の端に小さく常にいて、場面に合わせて表情・ポーズを差し替える（驚き＝顔の周りに効果）。
- 話す役（博士）は、話す時だけ大きく出て、説明が始まると小さくなって角へ（50.4–50.6秒）。

## 年末調整リールでの使い方（v12）
- 全体像のツリー → ①の枝へカメラが寄ってスポット → 基礎控除へ。
- 扶養・生命保険料控除の頭は、大きなツリーの上を**シュッと横に流れて**次の枝へ。
- 実際の用紙：一気に寄る → 画面ごと暗く、欄だけ明るく → 引き出し線で説明。
- 壁が上がる瞬間：カメラがグッと寄って戻る。
- 「6万円そのまま…」：数字だけ明るく残して暗くする。
