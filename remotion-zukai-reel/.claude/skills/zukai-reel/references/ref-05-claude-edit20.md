### ずっと出ている部品：右上の「この動画の演出」チェックリスト
- 濃い緑の角丸パネル（幅＝画面の約30%、右上）。見出し「この動画の演出」＋右に「n / 20」の数字。
- 01〜20の番号＋名前が縦に並ぶ。**今やっている演出の行だけ白い帯で光る**（文字は黒、番号は赤）。終わった行は白文字のまま。
- 一番下にオレンジのボタン「全20個の作り方つき」。
- 演出が切り替わるたびに、白い帯が1行下へ移り、数字が増える。＝「今どこ」がずっと分かる。

### 色・文字
- 背景のベージュ（#ECE7DC 前後）、濃い緑（#1E3A2C 前後）、オレンジ（#E07A4F 前後）、白。
- 見出しは明朝（細め・大きく）、ラベルは太いゴシック。
- 下の字幕：白い角丸の札に黒字、強調だけオレンジ（例「全部**Claude**で作りました」）。

## 締め（26–41）
- 「こんな動画が作れるようになると」＝これまでの演出の場面が、斜めのカードになって上に重なる（4枚）。
- 「1本これぐらいで」＝上に大きなオレンジの数字「¥81,703」→「¥15,000」（「1本」の小さい見出し）。
- 「しかもこれ全部Claudeだけ使えば」＝オレンジの角丸のロゴが左上から迫る。「誰でも作れます」の巨大な白文字。
- 「20個すべての作り方をまとめたサイト」＝サイトの画面のカードが上半分に（緑の見出し、プロンプトの黒い枠が縦に流れる）。
- 「プロフィールのリンクから」＝黒いプロフィール画面のカード → 指のカーソルがリンクをタップ → 最後はアカウント名の黄色い枠がポンと出る。

## たいちさんが使うときのメモ
- 20個は全部 Remotion で作れる（本人の映像の代わりに、太一のイラストや実写素材を入れる）。
- **使いやすい順**：05 色のビフォーアフター／07 レシート／08 カーテン／09 昔の映画風／12 カウントアップ／13 写真が並ぶ／14 写真に飛び込む／15 画面に書き込み／16 フィルム風／19 ファイルが落ちる。お金の図解とも合わせやすい。
- 右上のチェックリストは「〇個紹介します」系の台本（損する使い方5つ・おすすめ4つなど）にそのまま使える＝今どこかがずっと分かる。
- 見た目（濃い緑×ベージュ×オレンジ）はそのまま真似しない。動きと構成だけ使い、色は太一の黄色ノートに合わせる。
