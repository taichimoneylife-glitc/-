# 参考リール研究：Claude Opus 5.5 解説（Opus5.5＋Remotionで制作・37秒）

実写POV（肩越しにPC操作）＋"本物のUIっぽい"オーバーレイ図解を重ねた解説リール。
アニメーションは全部コード（Remotion）。**「常にズームで動く」演出**が最大の学び。
※人物・POVレイアウトは採用しない（全画面フラット図解のまま）。"動きの引き出し"だけ採用する。

## 採用する動きの語彙（次回制作から）
1. **常時ズーム／ケンバーンズ（最重要）**
   - どのページも、主図解や見出しを**出ている間ずっとゆっくり拡大**（scale 1.0→1.04 など）または微ドリフト。
   - 一瞬も静止しないので「画面が止まる」問題が根本から消える。
   - 実装：`const z = interpolate(f,[0,dur],[1,1.04],clamp)` を要素/シーンの `transform: scale(z)` に。
2. **バウンド付き登場（スプリング）**
   - カードや数字は `spring()` で**少し行き過ぎて戻る**pop-in。ただのフェード/popより高級感。
   - 実装：`const s = spring({frame:f-delay, fps, config:{damping:12,stiffness:120}})` を scale に。
3. **手描きマル／赤枠アノテーション**
   - キーワードや数字を**丸で囲む・枠で強調**（SVGパスの描画アニメ）。視線誘導に効く。
   - 例：「20年 0回」「約1,600万」を赤マルで囲む。
4. **強調時のプッシュイン**
   - VOが大事な数字を言う瞬間、その要素へ**軽く寄る**（scale 1→1.12 を短時間）。
5. **数字の見せ方**：点線ガイド＋大きな%がポップ（棒グラフ）。既存のBig/CountUpを強化。
6. **“本物のUI”モックの説得力**：アプリ/製品テーマでは実UIを再現すると一気に高品質（料金カード・スライダー・比較表・スプラッシュ）。投資テーマでは直接使わないが引き出しとして保持。

## テロップ
- 白の極太ゴシック＋キーワードだけ色付き（赤/黄）。2行・短く。footage上でも読めるよう縁取り/影。

## 実装メモ（Remotion）
- ケンバーンズは `AbsoluteFill` や各カードのラッパに `transform: scale()+translate()` を毎フレーム更新。
- スプリングは `spring({frame, fps})`。オーバーシュートで"生きてる"感。
- マルは `<path>` を `stroke-dasharray`/`strokeDashoffset` でdraw-onアニメ（既存 DrawLine の応用）。
- 「止まらない」を担保：各ページに最低1つの継続アニメ（ズーム or ドリフト）を必ず入れる。
