# 更新型保険 事実メモ（2026-11-17 WebSearch で確認）

| 項目 | 内容 | 出典の強さ |
|---|---|---|
| 更新型の仕組み | 保険期間が終わると、健康状態に関係なく同じ保障で継続できる。保険料は更新時の年齢・保険料率で計算し直すため、一般に更新前より高くなる | ①生命保険文化センター「更新について」 |
| 自動更新 | 申し出がなければ自動で更新されるのが一般的。やめる・減額するときは、更新の前に保険会社へ連絡が必要 | ①生命保険文化センター |
| 全期型 | 満了まで更新がなく保険料は一定。契約時の保険料は更新型より高い | ①生命保険文化センター |
| 更新の上限年齢 | 会社・商品で違う（例：80歳まで更新可能という商品あり） | ②価格.com の商品説明 |
| 保険料の例 30歳男性 | 定期保険・1,000万円・10年：月980円 | ②比較サイト（2026年7月度）。公式の保険料表は未確認 |
| 保険料の例 40歳・50歳／女性 | 男性 40歳1,890円・50歳4,340円／女性 30歳760円・40歳1,400円・50歳2,870円 | 依頼文（公式で確認済みとのこと）。自分では未確認 |
| 定期付終身保険の上乗せ部分の更新 | 依頼文では「同じ仕組み」。一次情報は未確認 → 台本では「〜ことがある」 | 未確認 |
