## 特徴
| 特徴 | 例 |
|---|---|
| 1行が短い（10〜20字）。名詞止めも多い | 「まず税金」「次に扶養」「そして問題が社会保険」 |
| 区切りの言葉で次を予告する | まず／次に／そして問題が／もう1つが／とはいえ／まとめると／だから |
| 問いかけで引っぱる | 「株か債券なのか？」「では10年後どうなるのか？」 |
| 見る人の心の声を先に言う | 「利息の50万円は損って思うかもしれないけど」「そこまで気にしなくてOK」 |
| 僕の考え・実体験を言い切る | 「結論僕はあえてローンで買います」「実際に僕も5%超えの債券を保有してます」 |
| 語尾がゆるい（です・ます一辺倒にしない） | 「〜払うことに」「ここが税金との大きな違い」「〜気にしなくてOK」 |
| 締めは「正解は1つじゃない」 | 「考え方は人それぞれ」「壁を超えないことが正解ではありません」 |
| 冒頭の型 | 年収の壁＝誰の話か＋知らないと損（金額）＋今なぜか＋解説します／車＝具体的な場面＋一見〜に見えて実は＋僕の考え含め |
