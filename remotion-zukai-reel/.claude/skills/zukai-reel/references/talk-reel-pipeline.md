# トークリール自動編集パイプライン（設計表フォーマット＋デザイン規則）

出典：参考リール制作者の公開ガイド（Notion「自分の動画をAIで編集｜Codex × Higgsfield × After Effects 実践ガイド」）を、私たちの環境（**Claude＋Remotion**）向けに翻案。
彼ら＝Codexがローカルの After Effects を操作してAEP＋MP4を作る。私たち＝**Claudeが Remotion(コード) で同じ成果物（編集可能プロジェクト＋MP4）を自動レンダー**する。やることは同一：**解析 → 秒数設計 → 編集可能プロジェクト → 確認 → 書き出し**。

## 全体の流れ（この順で回す）
1. **素材集約**：正面動画（mp4/mov）＋台本（あれば）＋ロゴPNG（透過推奨）＋参考画像。
2. **動画解析**（編集の前に必ず）：
   - 尺・解像度・fps
   - **各フレーズの開始/終了秒**（faster-whisper の word_timestamps）
   - 台本と実発話の差／言い直し・無音・音量
   - **顔・口元・手を避けて文字/図解を置ける場所**（フレーム抜き出しで確認）
   - HDR(HLG/10bit)素材は Remotion 用に **SDR H.264 へ変換**（zscale+tonemap=hable→bt709, yuv420p）してから下敷きにする。
3. **秒数入り設計表**を作る（下記フォーマット）。**全画面図解と実写の時間配分**を出す（参考例は33.27秒中 図解≈11.46s / 実写≈21.81s ＝おおよそ 図解1:実写2）。
4. **Remotionで生成**：実写下敷き＋語同期テロップ＋図解パネル＋寄り＋SFX。シーンごとにコンポーネント分割（参考例はAEで演出7＋字幕＋MASTER＝9分割）。
5. **確認**（下のチェックリスト）→「**場所＋変更内容**」で1点ずつ修正。
6. **書き出し**：投稿用MP4（H.264）。fpsは元動画に合わせる。

## 設計表フォーマット（これを埋めてから実装）
| 開始s | 終了s | 発話（テロップ） | 画面の見せ方 | 使う素材 | Remotionで作るもの |
|---|---|---|---|---|---|
| 0.00 | 1.58 | 投資で失敗したくないなら | 実写＋寄り | — | テロップ(失敗=強調) |
| … | | | 全画面図解 / 実写＋パネル | ロゴ等 | カード/矢印/数字 |
- 「共感」を伝える所は**本人の表情を見せる**（オーバーレイ控えめ）。
- 「手順」は**カード・矢印で図解**。「重要な数字」は**大きな文字＋動き**。

## デザイン規則（制作者が明文化・そのまま採用）
- **配色：明るい紙色の背景・濃い文字・ライム色のアクセント**（図解パネルに適用。※実写の上なので白極太＋縁取りテロップは維持）。
- **字幕は原則2行以内。顔・口元・手に重ねない**（上＝図解、下＝字幕、Insta UI域は避ける）。
- **本人の声が主役、効果音は控えめ**。
- 見出し（上）と字幕（下）で**情報を重複させすぎない**。
- 動くものを増やしすぎない＝**視線の行き先を1つに**。

## 確認チェックリスト（MP4を通しで見て）
- [ ] 発話と字幕の内容・タイミングが合う
- [ ] 文字が小さすぎず、表示中に読み終えられる（2行以内）
- [ ] 顔・口元・手が必要な場面で隠れていない
- [ ] 上の見出しと下の字幕が重複しすぎていない
- [ ] 動くものが多すぎず、どこを見るか分かる
- [ ] 声が聞き取りやすく、効果音が邪魔しない
- [ ] 最後に何をすればよいか（CTA）が分かる
- [ ] 音切れ・黒画面・素材欠落・文字化けがない

## Remotion実装メモ
- 下敷き：`<OffthreadVideo src={staticFile("talk.mp4")} />` を寄りズーム用ラッパ（transform: scale）で包む。
- テロップ：語同期（word ts→1〜4語チャンク）、白極太＋黒縁、キーワード色＋黄マーカー、下1/3・2行以内。
- 図解パネル：既存 `kit2.tsx`/`kit.tsx`（番号ステップ/フロー矢印/ゲージ=進捗/カード/DrawLine/StackTags）を**上部ヘッドルーム**に。色は明るい紙色＋ライムアクセント。
- 寄り：常時ゆっくり＋キーワードでプッシュイン。
- SFX：`SfxTrack` を出現ごとに、ただし**控えめ**（声を消さない）。
- 実装済み雛形：`src/TalkReel.tsx`（初回完コピ試作）。次はこの規則に寄せて更新。
