> **全体構成（投資の三大原則と同じ）**：**冒頭トーク（実写・図解なし）→ 図解パート（＝下の図解1〜図解9＋3.5をビルド）→ 締めトーク（実写・図解なし）**。僕がビルドするのは**図解パートだけ**。冒頭・締めはあなたが実写で撮影しCapCutで前後に接続（＝投資リールと同じ）。※下の「図解10｜締め・CTA」は実写の締めトークの内容メモ＝図解としては作らない（必要なら最後に軽い静止エンドカードのみ）。

## 図解1｜フック：「入ってるから安心」が危ない（L3）
- 喋り：入ってるから安心？／いざ出ないことも
- 画面構成（上→下）：
  1. 見出し「がん保険、入ってますか？」
  2. 吹き出し『入ってるから、ウチは大丈夫』＋**安心顔の人**（保険証を持つ）
  3. 赤スタンプ **「ちょっと待って！」**（回転・バウンド）
  4. 下帯：中身が**今の治療と合ってない**と、いざ出ないことも
- アニメ：安心顔→（ちょっと待って!がドンと被る）→顔がハッと青ざめる差し替え。
- イラスト：`g2_relax_insurance`(安心顔+保険証) / `g2_shock_face`(ハッと) / ic_warning。

## 図解2｜がんの三大治療（“何をするか”まで／★連結図解・1枚で濃く）
- 喋り：手術・放射線・薬物療法が基本
- 中心ハブ「がんの三大治療」→線で3カード。各カードに**アイコン＋一言の仕組み＋ミニ特徴**：
  - **手術**：がんを切って取り除く／入院あり（イメージ：メス・手術室）
  - **放射線**：ビームで狙い撃ち／多くは通院・数週間（イメージ：照射装置）
  - **薬物療法**：抗がん剤・ホルモン剤・分子標的薬で**全身**に効かせる／通院で長期（イメージ：点滴＋錠剤）
- 下帯：「単独より**組み合わせて**治療するのが一般的」。
- アニメ：ハブ→線が3方向に伸びる→カードが1枚ずつPopIn→各カードのミニ特徴が後から出る。
- イラスト：`t_surgery`(手術) / `t_radiation`(放射線照射) / `t_drug`(点滴+錠剤) / ic_body_parts(全身)。

## 図解3｜お金の負担は“治療費だけじゃない”＝備える4つ（★超重要・分解して濃く）
- 喋り：治療費／治療に伴う出費／療養中の生活費／収入の減少、が重なる
- **4ブロックを1つずつ開く**。各ブロック＝見出し＋中身の具体例を**小アイコンで複数**：
  1. **治療費**：三大治療・検査・入院（💊 ic_pill_iv / ic_hospital）
  2. **治療に伴う出費**：通院交通費🚃・入院の食事代🍱・差額ベッド🛏・ウィッグ・家族の付添費（4〜5小アイコン）
  3. **療養中も続く生活費**：食費・住宅ローン🏠・教育資金🎒・老後資金👴（止まってくれない）
  4. **収入の減少**：働けない/時短で給料ダウン📉
- クライマックス：4ブロックが**中央に集まって重なる**→「重なると家計が一気に苦しい」（赤・特大）。
- アニメ：各ブロックの小アイコンがパラパラ出る→最後に4つが中央へスライド集合。
- イラスト（新規多め）：`c_cost_treat` `c_cost_commute`(電車) `c_cost_meal`(食事) `c_cost_bed`(差額ベッド) `c_cost_wig`(ウィッグ) `c_cost_family`(付添) `c_life_food` `c_life_loan`(家) `c_life_edu`(ランドセル) `c_life_old`(老夫婦) `c_income_down`(給料減)。

## 図解3.5｜家計のバランスが崩れる（★ここでガツンと自分ごと化）
- 喋り：ただでさえ住宅ローンや積立もあるのに、これが重なると家計のバランスは崩れる
- 図で解説：**天秤／シーソー**。
  - 左の皿（これまでの家計）：住宅ローン🏠・車のローン🚗・毎月の積立・教育費🎒…でギリギリ均衡
  - 右に **がん（治療費＋収入の減少）** がドンと乗る → 天秤が**ガクッと傾いて崩れる**
- 一撃（赤・特大）：「**対策しないと、家計は崩れる**」。
- アニメ：バランスが取れている→右にがんブロックがドスン→傾く→左皿のコイン/家計アイコンがこぼれ落ちる。
- ブリッジ：「だから、がん保険で“ここ”を補う」→次（守り方2本柱）へ。
- イラスト：`c_balance_break`(傾く天秤/崩れる家計) ＋ ic_balance_scale / c_life_loan / `c_car_loan`(車ローン)。

## 図解4｜守り方は2本柱（★タイムラインで違いを見せる）
- 喋り：診断一時金／月額給付＝「なった時」と「治り続けるまで」
- 図：横タイムライン（診断→治療→療養）。
  - 上レーン **診断一時金**：診断の瞬間に**一括ドカン**（大きな札束が1回）
  - 下レーン **月額給付**：治療の各月に**小さな給付が毎月ずっと**（コインが横に連続）
- 2本柱が下から支える絵＝「なった時」＋「治り続けるまで」。
- アニメ：診断→一時金ドカン→その後、月ごとにコインがポンポン横に並ぶ。
- イラスト：`c_lumpsum`(一括の札束) / `c_monthly`(カレンダー+毎月コイン)。

## 図解5｜診断一時金を“詳しく”（★これが何かをイメージ）
- 喋り：まとまったお金を自由に使える安心
- 図で解説：
  - 「がんと**診断されたら**、まとまったお金が**一括**で」（例 **50〜200万円**を大きく）
  - **使い道は自由**＝中心の札束から4方向へ：医療費／生活費／収入の穴うめ／家族のため（アイコン）
  - 補足：**再発で何度も出るタイプ**も（1回型/複数回型）
- アニメ：診断→札束ドカン→4用途へ矢印が伸びる→「自由に使える」帯。
- イラスト：`c_lumpsum` / ic_wallet_coins / ic_balance_scale。

## 図解6｜月額給付を“詳しく”（★長期戦に効く）
- 喋り：長引く治療にずっと効く
- 図で解説：
  - 「治療を受けている**間、毎月**給付」（例 **月10万円**）
  - 治療が**続く限りずっと**＝カレンダーに毎月コイン、横に長く伸びる
  - 種類：抗がん剤治療給付／自由診療給付 など
  - 強み帯：「一時金が尽きても**ここが支える**＝長期戦に強い」
- アニメ：カレンダーが右に伸び、毎月コインがポンポン。棒が右肩に長く伸びる。
- イラスト：`c_monthly` / ic_calendar_years / ic_pill_iv。

## 図解7｜だから“組み合わせ”が最強（★弱点を補い合う）
- 喋り：この2つを組み合わせるのがコツ
- 図：一時金（最初の大きな出費をカバー）＋月額（長引く治療をカバー）を**重ねるとカバー範囲が埋まる**図（2つの帯を重ねて隙間が消える）。
- 帯：「“一時金＋月額”で、短期も長期もカバー」。
- アニメ：一時金の山＋月額の帯が重なり、空いていた部分が埋まる。

## 図解8｜公的保険の“外”＝先進医療・自由診療（★費用の内訳）
- 喋り：公的保険が効かない／先進医療は全額自己負担／重粒子線 約300万円
- 図で解説：
  - 費用バーを色分け：「公的保険でカバー」｜「**先進医療の技術料＝全額自己負担**」
  - **重粒子線 約300万円**を特大。高額療養費も**効かない**（赤注記）
  - 自由診療・未承認薬も対象外（スタック）
- アニメ：バーが伸びて自己負担部分が赤くドン→300万カウントアップ。
- イラスト：`c_advanced`(重粒子線/高額治療機) / ic_insurance_card / ic_warning。

## 図解9｜もう入ってる人の“見直し5チェック”（★各項目を説明）
- 喋り：再発で出る？上皮内がんは？通院対応？抗がん剤・ホルモン剤特約は？古い保険は通院0円も
- チェックリスト（□→✓ ポンポン）＋各項目に**ひとこと説明**：
  1. 診断一時金が**再発でも**出る（2回目以降も？）
  2. **上皮内がん**も対象（ごく早期。出ない/減額の保険あり）
  3. **通院**治療に対応（今は通院が主流）
  4. **抗がん剤・ホルモン剤特約**（その治療を受けた月に給付）
  5. **入院メインの古い保険**じゃない
- 一撃：赤特大「入院前提だと**通院に1円も出ない**ことも」。
- イラスト：ic各種＋`c_checklist`。

## 図解10｜締め・CTA（＝実写の締めトークの内容メモ／図解としては作らない）

- トーク構成（2つの相手に向けて）：
  - **まだ入っていない人へ**：もしなったら**家計が一気に崩れる**→「ぜひ検討を」（ic_warning＋崩れる家計）
